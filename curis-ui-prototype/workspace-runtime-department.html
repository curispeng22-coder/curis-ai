Curis/工作空间/通用模板 · 未装修
模板预览 · 无真实数据 去 装修台装修 →
这是一个尚未装修的通用工作空间——模板样板，不是运行现场。 一条业务承诺成立后会先落到这样一个空槽位空间，再由 CEO 在 装修台 里装修：声明本业务的北极星指标与口径、指定各阶段负责人、定义 CEO 介入点与失败出口。装修完成前，这里不会出现任何指标数值——系统不替业务编造口径。

结果条模板占位

（指标由业务在装修时声明。每个业务的北极星各不相同——软件研发看回归通过率、小红书看收藏率、短视频看完播率——因此模板不提供默认值）

北极星指标—待装修声明装修时必填：指标名 + 当前值 + 口径说明。口径要写清分子分母与排除项，避免事后解释权争议
辅助指标 ①—待装修声明建议选「产能类」——如本周期产出量 / 目标量
辅助指标 ②—待装修声明建议选「质量类」——如一次通过率 / 返工率
辅助指标 ③—待装修声明建议选「成本类」——如本周期模型与工具成本
辅助指标 ④—待装修声明建议选「价值类」——如 投入产出 或线索价值，须注明是否含人力与投放

责任链

（每个阶段必须有唯一负责人。至少保留一个 CEO 节点——对外发布、花钱、对外承诺、动权限、不可逆操作、扩大范围这六件事 AI 不得静默执行）

角色 ①待指派——建议承担「意图澄清与拆解」未装修
角色 ②待指派——建议承担「生产执行」未装修
角色 ③待指派——建议承担「结果回收与异常上报」未装修
CEO必选——对「验收 / 调整 / 暂停」负责，不可省略待装修确认介入点

运行管道通用槽位

（通用 9 槽位骨架：Intake 意图 → Produce 生产 1~N 段 → Deliver 交付 → Collect 结果回收 → Accept CEO 验收 → Review 复盘 → Improve 提升 → Archive 归档。装修时按业务改显示名、增删 Produce 段，槽位语义不变）
