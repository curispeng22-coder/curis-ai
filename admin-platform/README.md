# Curis Admin Platform Space

This space is reserved for the commercial platform management product.

## Ownership

Admin Platform owns platform-side operations:

- CEO / tenant / account management.
- Subscription, usage, billing, and invoice operations.
- Platform-level audit, security, and governance.
- Official capability supply:
  - official model catalog
  - official tool catalog
  - official connector catalog
  - official department templates
  - official industry capability packs
- Marketplace review and promotion when tenant-private capabilities are submitted for sharing.

## Non-Ownership

Admin Platform must not own Workspace company operations:

- Company department runtime configuration.
- CEO-created private tools, connectors, models, or departments unless submitted for platform review.
- Internal task execution details except metering, audit, and billing events.
- Workspace business decisions.

## Future File Placement

Place future Admin Platform files here:

- `admin-platform/app/` for Admin product implementation.
- `admin-platform/docs/` for Admin-specific product, architecture, and release docs.
- `admin-platform/tests/` for Admin-specific tests.

Shared contracts and rules belong in `shared/`, not here.
