# Key Decisions

Status: Deprecated

## KD-001: Current Gate Is Tool System v1.8

Decision: Sprint 1B is limited to Curis Workspace Tool System v1.8 - Controlled Self-Evolution Kernel.

Reason: The project must add strict evolution control before building company visualization.

## KD-002: Minimal Loop Is Protected

Decision: All Sprint 1B work must preserve:

```text
Task -> Orchestrator -> Auto Workflow Generator -> Employee -> Tool Router -> Tool Executor -> Result -> Development Learning -> Meta Development -> Evolution Governor -> Storage
```

## KD-003: Forbidden Scope

Decision: Sprint 1B forbids ROI, Employee CRUD, multi-agent systems, business modules, UI complexity, mock data, simulation mode, uncontrolled architecture changes, and automatic code self-modification without approval.

## KD-004: Low-Token Role Defaults

Decision: Role work starts from `knowledge/` files and the current issue, not full-repo reads.

Reason: The project needs lower token use and clearer role boundaries.

## KD-005: Five Merged Curis Operating Seats

Decision: The project operates through five merged seats. Standalone legacy roles are no longer active dispatch targets.

- 总控决策席
- 产品规划席
- 系统交付席
- 质量运行席
- 安全边界席

Reason: This preserves accountability without forcing every role into every task.

## KD-006: Sprint Advancement Requires Evidence

Decision: Sprint advancement requires 产品规划席 acceptance, 质量运行席 evidence, and 总控决策席 approval.

## KD-007: Pause Visualization For v1.6

Decision: User selected option A. Sprint 1 visualization is paused while Tool System v1.6 Meta Development System is implemented and verified.

## KD-008: Stability-First Controlled Evolution

Decision: Tool System v1.8 must enforce `STABILITY > OPTIMIZATION > EVOLUTION`.

Evolution is not automatic. Evolution decisions must pass threshold evaluation, architecture lock checks, simulation, risk analysis, and approval decision recording before any controlled update is allowed.
