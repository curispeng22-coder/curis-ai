# Knowledge Index

This folder is the low-token knowledge layer for Curis Workspace.

Read these files instead of scanning the whole repository.

## Files

- `NOW.md`: default recovery entry; read this first.
- `000_Project_Brief.md`: short project brief and current scope.
- `001_Project_History.md`: compressed history of major project changes.
- `002_Product_Vision.md`: product vision and sprint roadmap.
- `003_Architecture.md`: current system architecture summary and module boundaries for 系统交付席.
- `004_Workflow.md`: collaboration model and role workflow.
- `005_Key_Decisions.md`: durable decisions and active constraints.
- `CURRENT_CONTEXT.md`: compact current sprint, route, and active blockers.
- `archive/`: historical context retained for evidence, not default reading.

## Rule

Keep active files short. Link to detailed documents or archives instead of duplicating them.
