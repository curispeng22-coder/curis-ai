### 6.3 实际发现的产品断点（建议 CEO / Codex 裁定，非实现限制）

1. **「同一事实只保留一个来源」与跨区引用**：归因、评论、经验、发布回执之间互相引用，但原型只能做到「引用 ID + 可跳转」，**没有一个能回答「这条事实当前的唯一权威副本是谁」的视图**。建议：是否需要一层「事实源视图」。
2. **「同口径比较」在 v1 只做到并置**：跨平台指标不合并已落实，但读者要「同口径比较」时，界面只能并排展示不同单位 / 分母，**未提供换算或可比性判定**。这是产品决策，不是实现难度。
3. **经验「接受」之后没有自然的失效路径**：有停用与标疑，但「何时该重新审视这条经验」没有触发条件，只靠人记得回来。
4. **五层归因的第 4 层（Learning）与「写作经验」区存在职责重叠**：归因里直接产出经验候选，经验区又独立维护适用检查。本轮按「归因产出候选、经验区做适用检查」实现，边界建议由产品明确。
5. **空书与新书的经营语义**：新建 Book 是「空书 · 可手写」，但它没有方向、没有平台、没有节奏，**在经营首页与库存视图里几乎不产生信息**；新书进入经营视野的最小字段集建议明确。
