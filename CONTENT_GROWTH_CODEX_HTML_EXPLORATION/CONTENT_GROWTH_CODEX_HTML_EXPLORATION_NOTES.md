## 核心表达

七个长期专业区不变。经营以 Leader 的判断和账号组合为起点；市场观察保留研究范围、变化快照、来源与限制；参考按 Hook、Opening、Structure、Rhythm、Visual、CTA 拆解，形成带来源的 Pattern，再转选题和指定目标账号的提案。制作总览采用按方法分组的紧凑 Work Row，具体 Work 让图文页序、口播脚本、视频镜头或长文章正文占主位，员工与当前产物相邻。发布把已接受成品、执行方式、外部回执与观察窗分开。复盘从内容趋势和同指标比较进入证据、假设、实验、经验，再创建下一轮选题。

与旧 Design Agent 原型相比，本版从市场发现和经营判断出发，而不是七张相似的管理页；制作工作面根据产物形态变化；员工交流留在当前对象上下文；复盘显示同账号内容与同主题跨平台的时间曲线、可比性限制及 Learning 回流。旧目录未修改。

## 可实际操作的演示路径

市场信号 → 建立参考 → 拆解 Pattern → 选题 → 提案 → 制作 Work → 找负责人交流 → 修订版本 → 员工把关 → 人确认成品 → 建立发布项 → 外部效果未知 → 人工核验回执 → 趋势 / 比较 → 内容归因 → 经验候选 → 接受经验 → 下一轮选题。持续关注可新增、修改、暂停、恢复、立即检查、移除；账号档案可新增、修改和受历史引用保护地移除；内容数据可手动补录；素材可记录本地文件名称与授权范围。以上变化保存在浏览器 localStorage，刷新后保留，侧栏可确认重置。

## Product Findings（供 CEO 裁定，不修改 Authority）

1. Market Watch 的“立即检查”仍需要合法来源、频率、采集许可与失败/未知合同；原型只记录演示检查时间。
2. 研究参考可以保留来源和结构方法，但真正从视频/评论提取证据的能力尚未连接；不能把 Mock Pattern 当作平台验证结果。
3. 不同内容形式的产物工作面已分开，但原型并不包含完整编辑器。员工讨论保留上下文，正式修改仍通过 Work 中明确的修订与再次把关完成。
4. 跨平台同名指标的定义、曝光分发、形态与受众不同；并排曲线不是可直接排名的业绩结论。图文完播率为不适用，不记 0。
5. 当前演示中的发布核验是用户填写链接与依据后的本地状态；真实外部效果、授权和平台回执仍需要实施阶段单独验证。

## Mock / Unknown

所有市场信号、热度、账号目标、内容数据、评论、员工回复和发布历史都是演示数据；没有真实模型调用、平台 API、浏览器采集、计算机发布、权限绑定或后端存储。本地文件导入只记录文件名、类型和授权说明，不读取或上传文件正文。人工“已核验上线”只表示演示中已填写核验依据，不代表真实平台发布。单条内容缺少完整观测时显示 Unknown / 不适用，不补造曲线。
