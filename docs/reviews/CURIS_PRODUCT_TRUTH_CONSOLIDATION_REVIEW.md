## 9. Browser / Model / Background / Recovery Changes

- Browser隔离session/账号/权限、观察、上传下载、localhost、接管与断线效果核验；Reader/Search不混Company Search。
- Model声明/发现/测试/新鲜度分离；SUPPORTED/UNSUPPORTED/UNKNOWN分别按用途证据。动态tenant-private模型合法性保持；AI Ready不只看DB。
- Work explicit→Employee purpose→Company default仍受Permission/Data/Budget/Capability；fallback不隐式换数据目的地/降能力或重发未知外写。
- 后台opt-in与实际Running分开，停止全部不撤销远端事实；重开接同Runtime，非24/7或Cloud promise。
- effect confirmed / unknown / verification required / safe retry / cannot replay是产品效果判断，不要求同名Runtime enum。Approval实质变化失效。
- 完整Backup包含DB/Managed Files/Manifest/Integrity；排除Credential/Cookie/Keychain Secret/Browser Profile，恢复后重连/核验才继续外写。
