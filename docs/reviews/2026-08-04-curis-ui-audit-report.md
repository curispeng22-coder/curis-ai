# Curis UI 原型审核报告

**审核日期：** 2026-08-04
**审核范围：** `curis-ui-prototype/` 17 个用户可见页面 + `_system/` 冻结设计系统 + `curis-prototype.js` mock 层
**审核基准：** `_system/tokens.css` / `shell.css` / `theme.js` / `assistant-drawer.css`+`.js`（冻结唯一真相源）
**审核方法：** 静态 grep/ripgrep + Puppeteer 渲染探针（17 页 × dark/light，5 页 × system+OS 深/浅）+ 计算样式取证

## 审核结论

**未达到 Frozen 可交付标准。** 存在 **1 项 P0 阻断**（mock 层在运行时系统性覆盖冻结 `--ui-*` 令牌，导致深色态全站渲染旧调色板、状态色渲染违禁蓝）、**5 项 P1 应修**、**9 项 P2 优化**。冻结令牌转换与主按钮纪律两项在「静态/局部」层面已做，但运行时被 `curis-prototype.js` 的全局样式注入与第二主题控制器架空，必须修复后才能视为 Frozen。

### 通过项

- **令牌引用骨架**：17 页 `<head>` 均链接 `_system/tokens.css` + `shell.css` + `theme.js`；`curis-prototype.js` 自动加载 `assistant-drawer.css/.js`（`curis-prototype.js:14-27`）。
- **冻结 `--ui-*` 令牌定义完整**：`--ui-bg`/`--ui-surface`/`--ui-accent` 等在运行时取值正确（`#1a1c1f`/`#222529`/`#32f08c`），未被 P0-1 改写；问题在于页面消费的是被覆盖的私有令牌。
- **主按钮纪律（`.btn-primary`）**：16 个可探针页 `.btn-primary` 运行时计数均 ≤ 1（P1-2 的遗留 `.primary` 为另一独立问题）。
- **助理 UI 统一**：运行时全站 `#assistant-fab` 在、`#assistant-drawer` 在、`#curis-companion` 不在、`.ask-fab=0`、`#drawer` 不在——旧助理 UI 已彻底退役，Global Assistant 抽屉统一生效。
- **mock badge**：17 页 topbar 均注入 `.mock-badge[data-curis-auto]`（`injectMockBadge`，`curis-prototype.js:7026`）。
- **主题无深浅混杂**：dark 全暗、light 全亮、system+OS浅=light、system+OS深=dark，无元素跨态泄漏（Bug-1 修复有效）。`body[data-curis-neutral]` 在全站生效，neutral shell 一致。
- **布局**：标准 shell 页 sidebar(220px)+main 正确并列（grid `220px 1fr` 或 flex）；1440 视口下 `scrollWidth=1440` 无横向滚动；无固定 `1440px` 画板容器。
- **导航方案 A**：四分组（公司 / 工作空间 / 经营工具 / 公司资源）正确，运行时页归入「工作空间」，active 项高亮。
- **违禁词静态清洁 + 翻译表纠偏**：静态 HTML 无 `Blueprint`/`Outcome`/`Evidence`/`赌注`/`下注`/`回报`/`AI员工`；`curis-prototype.js` 翻译表（`:171/:218/:221/:244/:268` 等）主动将 Blueprint→蓝图、Outcome→业务结果、Evidence→证据、赌注/下注→业务方向、回报→反馈，纠偏有效（`AI 员工` 为唯一漏网，见 P1-3）。
- **ROI/KPI 首现备注**：`ROI（投入产出）` 在 7 页（xhs/shortvideo/ceo-desk/finance/decision-room/business/operating）按首现格式出现。
- **字体/圆角/阴影**：Inter 经 `tokens.css:9` `@import` 加载；圆角 `--ui-radius`/`--ui-radius-sm`、阴影 `--ui-shadow` 在 `shell.css` 统一。
- **空/错/骨架状态**：`shell.css` 定义 `.skeleton`/`.empty-state`/`.error-state`/`.mock-badge` 组件。
- **抽屉可访问性**：`assistant-drawer.js` 注入 `role="dialog"`/`aria-modal="true"`/`aria-label`，ESC 关闭、关闭按钮聚焦、点击遮罩关闭均生效。
