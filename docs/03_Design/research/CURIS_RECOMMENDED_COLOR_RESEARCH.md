# CURIS 推荐配色研究

Status: Review
Authority Class: RESEARCH
Disposition: 视觉参考 / 不构成 Frozen Authority
Owner: Product / Design
Updated: 2026-09-21

> 本文根据抖音账号“東丁设计”公开作品中的标题主题与可见配色画面整理。颜色值为截图画面的近似取样，不是原作者的官方色值，也不直接冻结 Curis Hex Token。

## 1. 筛选标准

Curis 需要同时满足：

- 安静、专业、可信；
- 有清晰视觉焦点，但不过度刺激；
- 能承载丰富 Work、Result、Evidence 与 Decision；
- 适合中文优先、长时间使用的桌面产品；
- 保留 Deep Green 的品牌可能性，但不把产品做成大面积彩色主题。

## 2. 推荐结论

最适合 Curis 的组合是：

**雅致中性基础 + 温和绿色焦点 + 少量暖色辅助。**

建议优先验证：

1. 世界上最雅致的配色
2. 舒服的配色 / 高级感撞色搭配
3. 世界上最耐看的配色

粉色、珊瑚色和雾蓝适合作为空状态、辅助状态或 Professional Accent，不建议成为 Curis 全局主色。

## 3. 五个推荐颜色方向

### 3.1 世界上最雅致的配色

[来源视频](https://www.douyin.com/note/7683362437647808107)

截图证据：本次浏览会话已打开并捕获该视频画面；点击上方来源链接查看原视频。

**画面主题：** 舒缓 / 精致 / 信赖。

**近似色板：**

| 角色 | 近似颜色 | 建议用途 |
|---|---|---|
| 深蓝 | `#142B69` | Focus、重要对象标题、关键判断 |
| 奶油白 | `#F1EFDD` | 温和背景、阅读区域 |
| 银灰 | `#C5C5C1` | Subtle Surface、分隔、辅助容器 |
| 黑 | `#090909` | 极少量高对比文字/边界 |

**推荐理由：**

- 最接近 Curis 的 Calm Surface；
- 深蓝能承担 Strong Focus，而不需要高饱和色；
- 奶油白比纯白更适合长时间阅读；
- 银灰可以支持低对比层级，不依赖大量 Card。

**Curis 建议：** 作为 Direction A / Quiet Neutral 的主要参考，不直接复制黑底和银色金属质感。

### 3.2 舒服的配色 / 高级感撞色搭配

[来源视频](https://www.douyin.com/note/7687487009795585961)

截图证据：本次浏览会话已打开并捕获该视频画面；点击上方来源链接查看原视频。

**画面主题：** 舒服 / 高级感 / 撞色，但仍保持柔和。

**近似色板：**

| 角色 | 近似颜色 | 建议用途 |
|---|---|---|
| 温和黄绿色 | `#B8D875` | Curis focus、Employee presence、Active state |
| 鼠尾草绿 | `#C8D5B4` | Focus Soft、选中背景、轻量提示 |
| 深蓝 | `#142B69` | 文字、重要对象、稳定对比 |
| 黑 | `#090909` | 仅作高对比参考 |

**推荐理由：**

- 与 Curis 现有 Deep Green 方向有自然联系；
- 绿色可以表达生长、工作推进和可用焦点，但不必变成“AI 霓虹”；
- 深蓝压住绿色的轻飘感，保留专业度；
- 适合形成 Curis 的品牌记忆点。

**Curis 建议：** 作为 Direction B / Curis Strong Focus 的重点参考。实际产品中应降低绿色面积和饱和度，保留“点亮焦点”而非“绿色皮肤”。

### 3.3 世界上最耐看的配色

[来源视频](https://www.douyin.com/note/7681181470875294399)

截图证据：本次浏览会话已打开并捕获该视频画面；点击上方来源链接查看原视频。

**画面主题：** 素雅 / 静谧 / 治愈 / 经典耐看。

**近似色板：**

| 角色 | 近似颜色 | 建议用途 |
|---|---|---|
| 柔珊瑚橙 | `#ED765F` | Warm Accent、需要关注但非危险的状态 |
| 深蓝 | `#1F3D55` | 标题、导航焦点、稳定对比 |
| 柔灰白 | `#E7E3DA` | 阅读表面、背景层 |
| 深炭黑 | `#111111` | 高对比文字或图像底 |

**推荐理由：**

- 有温度，但不像消费品牌橙色营销页；
- 珊瑚橙适合少量表达“正在发生/值得注意”；
- 深蓝保持理性，避免页面过甜；
- 可用于 Result、Insight、Review 等需要一点生命力的区域。

**Curis 建议：** 作为暖色辅助，不作为品牌主色，也不用于所有 CTA。

### 3.4 世界上公认最美的颜色

[来源视频](https://www.douyin.com/note/7687084283407924202)

截图证据：本次浏览会话已打开并捕获该视频画面；点击上方来源链接查看原视频。

**画面主题：** 最美 / 感染力 / 视觉盛宴。

**近似色板：**

| 角色 | 近似颜色 | 建议用途 |
|---|---|---|
| 玫瑰粉 | `#D88AA4` | 少量 Professional Accent |
| 灰粉 | `#D7C1C8` | 柔和 Focus Soft、空状态 |
| 深蓝 | `#142B69` | 文字与视觉锚点 |
| 黑 | `#090909` | 仅作对比背景 |

**推荐理由：**

- 具有品牌表达能力，能让 Curis 不止是灰度工具；
- 粉色与深蓝的组合有辨识度，但仍可保持克制；
- 适合研究、洞察、创意内容等专业区域的辅助强调。

**Curis 建议：** 只作为受控 Professional Accent；不能把 XHS、RD 或 Commerce 分别变成彩色主题。

### 3.5 世界上最温柔的配色

[来源视频](https://www.douyin.com/note/7685679234719614918)

截图证据：本次浏览会话已打开并捕获该视频画面；点击上方来源链接查看原视频。

**画面主题：** 甜蜜 / 治愈 / 温柔 / 松弛 / 安心感。

**画面可见色值：**

| 角色 | 画面标注/近似颜色 | 建议用途 |
|---|---|---|
| 粉色 | `#EC89A8` | 欢迎态、轻量情绪辅助 |
| 雾蓝 | `#9FC4D7` | Calm Surface、辅助信息 |
| 奶油白 | `#FBEDEA` | 空状态、阅读背景 |
| 暖灰 | `#D8D5D2` | 分隔、次级表面 |

**推荐理由：**

- 能为 Curis 提供柔和、人性化的低压力状态；
- 雾蓝比高饱和蓝更适合长时间使用；
- 适合空状态、首次进入、轻量反馈和非关键辅助区。

**Curis 建议：** 不进入默认品牌主色；只作为低频辅助方向，避免产品变得过于生活方式化。

## 4. 推荐优先级

| 优先级 | 方向 | 进入 Curis 的方式 |
|---|---|---|
| 1 | 雅致中性 + 深蓝 | Shared Surface / Reading / Research |
| 2 | 温和黄绿色 + 深蓝 | Brand Focus / Active / Employee Presence |
| 3 | 珊瑚橙 + 深蓝 | Warm Accent / Result / Insight |
| 4 | 玫瑰粉 + 深蓝 | 受限 Professional Accent |
| 5 | 粉 + 雾蓝 + 奶油白 | Empty State / Welcome / Low-pressure feedback |

## 5. 不建议直接复制的视觉特征

- 大面积纯黑背景；
- 所有组件使用金属银色边框；
- 高饱和撞色铺满页面；
- 用颜色代替层级、状态文字或焦点指示；
- 把每个色组做成独立 Card；
- 为 XHS、RD、Commerce 各自建立完整主题皮肤。

## 6. 下一步

将前三个方向带入现有 `CURIS_VISUAL_EXPLORATION_BRIEF.md` 的 Research 与 Employee Conversation benchmark：

- Direction A：雅致中性基础；
- Direction B：雅致中性 + 温和绿色 Strong Focus；
- Direction C：Direction B + 极少量 Professional Accent。

保持相同信息架构、内容与交互，只比较视觉系统。最终由 CEO 选择，不在本文冻结 Hex 或更新 Frozen Design System。
