# 1. 「今天到底做什么」不是拍脑袋

专业团队选选题是一个**多信号加权 + 业务目标过滤**的过程，而非「哪个热做哪个」或「全不追」。至少纳入以下输入：

- 当前热点（平台热搜、上升词）
- 平台流量方向（算法在加权什么，如抖音收藏/复访、小红书搜索、B站深度）
- 官方活动 / 创作者计划（直接 = Growth Opportunity）
- 用户需求（评论/私信/搜索高频问题）
- 高频评论问题（可被内容直接回答）
- 粉丝兴趣（历史高互动主题）
- 竞争对手内容（差异化而非模仿）
- 历史高表现主题（放大已验证）
- 品牌长期内容方向（不跑偏）
- 搜索趋势（长尾需求）
- 产品/业务近期变化（Changelog → 内容）
- 时效性（节日、节点、活动窗）
- 内容生命周期（evergreen vs 时效）
- 制作成本（ROI 视角）
- 商业价值（是否服务主目标）

# 2. 热点处理的「两极避免」

- **避免「所有热点都追」**：热点与账号定位/目标不符时硬蹭，会打乱标签、稀释受众、拉低转化。抖音兴趣标签算法会因内容跨界而无法稳定锁定精准人群。
- **避免「完全不追热点」**：会错过时效性流量入口与平台活动红利。小红书 RED 大赛、抖音 AI 创作浪潮计划、B站分区活动都是「该追」的官方 Growth Opportunity。

**判别框架（是否追这个热点）：**
1. 与经营方向/账号定位是否契合？
2. 与当前业务目标是否相关（曝光/获客/转化）？
3. 是「上升期」（竞争小、易卡位）还是「爆发期」（红海）？
4. 能否提供差异化角度（而非复述）？
5. 时效窗口是否够制作发布？

> 实操：用「热点 + 痛点 + 价值三维定位法」（第三方运营方法，NEEDS VERIFICATION 作为通用思路）——优先选上升期热点，从评论区提取高频问题直接回应，确保提供「可执行方案」而非空泛观点。

# 3. 内容类型组合（Content Mix，按经营意义而非分类而分类）

重点不是贴标签，而是**组合的经营价值**。常见内容角色：

| 类型 | 经营意义 | 典型形态 |
|---|---|---|
| Evergreen（常青） | 长期被搜索消费、沉淀价值、抗波动 | 教程、清单、方法论、科普 |
| Trending（时效） | 抓窗口流量、蹭平台活动 | 热点解读、活动参赛 |
| Campaign（活动） | 配合产品发布/节点/平台大事件 | 发布季、节日、挑战赛 |
| Product（产品） | 直接服务转化/用户教育 | demo、测评、更新解读 |
| Community-driven（社区驱动） | 由用户问题/评论生成，强粘性 | 答疑、粉丝故事、UGC 回应 |
| Educational（教育） | 建立专业信任、高收藏 | 系列课、避坑、拆解 |
| Opinion（观点） | 建立人格与立场、引发讨论 | 行业判断、反共识 |

**组合原则：**
- 不让账号每天随机做内容，而是形成自己的 Mix 比例。
- 冷启动期：以 Evergreen + Educational 建立标签与搜索长尾，少量 Trending 试水。
- 增长期：放大已验证高表现类型，加入 Campaign 借活动。
- 稳定期：Mix 稳定，引入 Product/Community 加深关系与转化。
- 转化期：提高 Product/Campaign 占比，但仍保留 Evergreen 维持基本盘。

**动态管理：**
- **探索新类型**：当某类内容长期表现平庸或目标变化。
- **扩大成功类型**：历史高表现且服务目标的类型加量。
- **停止低质量类型**：连续观察窗口（非单次）表现差且无业务价值。

# 4. 平台政策与流量机会（长期跟踪机制）

运营团队应持续把平台变化当作**经营输入**而非新闻：

- 平台鼓励什么（如抖音 2026 重收藏/复访/铁粉；小红书重搜索长尾与中长视频 90 天窗口；B站重深度与正向度；TikTok 重完播/复看/原创；YouTube 重 watch time% 与 Shorts→长视频飞轮）。
- 平台限制什么（如小红书导流私域封号、AI 内容强制标注；B站频繁改稿限流；TikTok 前 2 秒划走率阈值）。
- 平台活动是什么（抖音四大计划、小红书 RED 大赛/蒲公英分成、B站分区活动、YouTube Shorts 更新）。
- 创作者计划（蒲公英/花火/创作激励/Creator Fund）的门槛与变现路径。
- 内容形式曝光变化（横/竖、长短、图文/视频）。
- 审核/合规规则变化（强制 AI 标注、社区公约 2.0 反对制造对立）。

**机制**：情报系统（Doc2）将政策/活动变为 Growth Opportunity → 评估「适合当前账号否 / 值得参加否 / 做什么 / 何时完成」→ 进选题与排期。平台实时事实**必须官方来源验证**，不得凭旧知识把规则写死。

# 5. 选题的优先级排序（给 AI 的方法）

AI 对每个候选选题应计算一个**业务适配分**，而非热度分：

```
选题分 = w1·目标契合度 + w2·受众匹配度 + w3·平台信号契合度
       + w4·差异化角度 + w5·时效窗口 + w6·制作可行性
       − w7·标签漂移风险 − w8·合规风险
```

- 权重随账号目标与阶段可调（获客型重 w1/w2，曝光型重 w3/w5）。
- 输出应为排序后的「选题候选池」，并标注每条的支撑信号（来自哪个源/哪个用户问题）。
- 避免「相关≠因果」：某选题上次火不代表这次火，需结合窗口与重复证据。

# 6. 系列化与栏目化（提升复访与铁粉）

多平台共性：单条爆款偶然性下降，**系列化/栏目化**显著提升复访与铁粉（抖音、B站、小红书均强调）。方法：
- 围绕核心主题建固定栏目，每期解决一个具体问题。
- 用户看完一期主动进主页看其他 → 被算法判为高价值账号。
- 产品上应允许用户/AI 定义「栏目」并维持更新节奏。

---

# 7. 内容形态的跨平台再创作（衔接 Doc1 第七节、Doc5）

同一选题在五平台应**差异化制作**而非群发：
- 抖音/TikTok：竖短、强钩子、前 1.5–3 秒定生死、完播/复看优先。
- 小红书：图文/中长视频并重，重搜索关键词、封面与标题、收藏价值、真实感。
- B站：中长深度、强信息密度、社区语境、三连引导。
- YouTube：Shorts 钩子 + watch time%，并与长视频形成飞轮。

基础素材（脚本骨架、数据、观点）可共享，成片必须平台化再创作。

---

# 8. 给产品设计的输入

- 「选题员工」需持有：选题标准（权重）、Content Mix 比例、优先级规则、栏目定义。
- 用户应能查看「当前选题候选池」及每条的支撑信号来源。
- 平台活动/政策应自动以「Growth Opportunity」卡片呈现，含适配度评估。
- 内容类型组合应可视化、可调整，且随阶段与数据演化。
