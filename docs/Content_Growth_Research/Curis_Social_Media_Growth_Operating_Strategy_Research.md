# 1. 研究定位与边界

本研究的对象不是「一个能自动生成视频并发布的 Agent」，而是一套**可持续运行的内容经营操作系统**：

> 发现机会 → 选题 → 制作 → 发布 → 用户互动 → 数据分析 → 策略调整 → 下一轮增长

我们研究的是**业务经营方法**，而非产品形态。下述所有结论后续由产品设计专家翻译成用户可见的能力与界面；本文不预设任何页面、字段或前端实现。

研究边界（明确不做什么）：
- 不设计 Curis UI、不定义视觉/交互。
- 不设计软件架构、Runtime、数据库。
- 不修改任何 Frozen Contract、Product Blueprint、XHS/RD、Connector。
- 不输出「每天发 3 条」「晚上 8 点最好」「热点都要跟」这类死规则。

研究粒度：至少到三层——**经营方向（Business Direction）+ 具体账号（Account）+ 平台（Platform）**。同一平台（如抖音）下，AI 科普、个人 IP、产品品牌、测评账号的策略应显著不同。

# 2. 一个社媒账号到底为什么经营（经营目标）

账号必须为某个**业务目标**服务，否则所有指标都是虚荣指标。常见目标：

| 目标 | 核心含义 | 更看重的指标（非播放量） |
|---|---|---|
| 品牌曝光 | 让更多人知道存在 | 触达、分享、SOV（声量份额） |
| 粉丝增长 | 建立可触达人群 | 关注转化、取关率、铁粉占比 |
| 潜在客户获取（Lead） | 拿到可跟进的人 | 收藏、私信、留资、站外转化 |
| 产品转化 | 直接卖货/订阅 | 点击、下单、GMV、ROI |
| 个人影响力 | 建立专家心智 | 转发、被引用、媒体/活动机会 |
| 社区经营 | 养忠实用户群 | 评论深度、复访、社群活跃 |
| 知识传播 | 改变认知/教育 | 收藏、完播、回看 |
| 带货 | 交易闭环 | 橱窗/蓝链成交、客单 |
| 用户教育 | 降低使用门槛 | 收藏、搜索长尾、私信问题下降 |
| 产品支持 | 答疑/减少工单 | 问题被内容覆盖后工单下降 |

**关键判断**：播放量高 ≠ 业务成功。若目标是获取潜在用户，则**收藏、关注转化、私信、站外转化**比单纯播放重要得多。不同目标直接决定：
- 选题方向（曝光型追广度，获客型追痛点）
- 内容类型（转化型重 demo/测评，影响力型重观点/深度）
- 指标（见第十节）
- 发布频率（品牌维持声量 vs 获客重质）
- 互动策略（获客型须认真回私信）
- 复盘标准（以目标指标而非播放量论成败）

> 给产品设计的输入：一个账号在创建时必须先声明「主目标」与「次要目标」，后续所有策略建议都由此派生。目标可在经营中调整，但调整属于策略层变化（见 Doc7 决策边界）。

# 3. 平台差异不是细节，是结构

五个平台在**推荐机制、内容形式、用户行为、生命周期、互动方式、活动、创作者计划、成长阶段**上差异巨大。必须区分「通用经营方法」与「平台化方法」。

**已查证的关键平台事实（2025–2026，来源见注释）：**

- **抖音**：2026 算法权重重构为「收藏率 > 复访 > 铁粉互动 > 整体停留 > 5 秒完播 > 评论质量 > 点赞」（第三方分析：布马《抖音算法·2026 深度解析》、搜狐《抖音运营新算法》）。流量渠道从单一推荐扩展到「推荐 ~45% / 搜索 ~25%（增速最快）/ 商城 ~15% / 私域 ~15%」。采用 7 日长效赛马，好内容可在搜索/关注长尾持续分发。AI 内容强制标注。2025 创作者大会推出「AI 创作浪潮计划」（即梦 AI，含工具+课程+现金流量扶持）。
- **小红书**：平台承诺将 50%+ 大盘流量分配给千粉以下创作者；中长视频持续推荐 90 天；CES 评分中转发/评论权重（各 4 分）高于点赞/收藏（各 1 分）；搜索流量占比逼近 50%，搜索转化率为推荐流量 4.1 倍；社区公约 2.0（2026.01）强制 AI 标注、严禁导流私域封号、内容重复度高清零权重；蒲公英视频分成计划（YouTube 式）预计 2026 下半年全面上线；RED 新生代创作大赛（上半年最重要创作活动）鼓励 2 分钟以上中长视频+千字长文。
- **B站**：硬币（coin）是最重要算法指标；分区差异化分发（知识/科技区「有效观看时长权重」高 40%，小众分区有定向保护）；热门榜隐性加权「内容正向度 35% / 稀缺度 30% / 互动增速 25% / 社区信用分 10%」；冷启动窗口约 3h→7h→13h，89% 视频进入长期沉默池靠搜索/粉丝存活；新账号（开创作激励且少粉）初始 3h 窗口被跳过；限流高发于「低创/营销号」「频繁改稿」「转载投自制」。
- **TikTok**：兴趣图谱（interest graph）而非关注图谱；测试管道 200–500 人冷启；排名信号按权重为「完播/观看时长 > 复看 > 互动（评论+分享>点赞）> 主页访问 > 账号信任分」；账号年龄/发布历史构成隐藏信任分；前 1.5–2 秒划走率 >35% 致冷启失败；分享到私信权重高于分享到其他 App；原创/真人出镜被加权，低质转发/带水印被降权。
- **YouTube（Shorts）**：Shorts feed 驱动 >60% 自然观看（Metricool 2026 研究，79 万视频样本）；确认排名信号为「观看 vs 划走、平均观看时长/%、满意度（赞/踩/后观看调查）、观看历史与主题兴趣、声音、竞争与季节性」；**订阅数、发布频率、跨平台分享都不是排名信号**；2026.01 起更长 Shorts（达 3 分钟）获同等待遇，且 Shorts→长视频转化成为正向信号（飞轮）；最小账号增长最快、最大频道（>1M）单条观看下降最多。

> 注：抖音/小红书/B站的具体权重数字多来自第三方分析机构（布马、青瓜传媒、运营派等），并非平台官方公开白皮书；TikTok/YouTube 部分信号有官方 Creator Portal / 工程博客支撑。一切用于产品判定的具体数值应标 **NEEDS VERIFICATION**，并以平台官方来源为最终依据。

**元警示（来源质量，复查补充）**：本轮检索到的部分中文「平台算法解析」实为 SEO/营销号或疑似 AI 生成内容（如布马《抖音算法·2026 深度解析》、部分搜狐/青瓜传媒转载），其具体数字（如下两条）**可信度最低，不得编码为产品规则**：
- 「教育类内容初始推荐权重 1.3 倍、科技 1.2 倍、娱乐 0.8 倍」——单一来源 SEO 推测，标 **LOW CONFIDENCE / NEEDS VERIFICATION**。
- 「新账号前 5 个作品自动进入新人保护期、初始流量池 500–5000」——与抖音官方「冷启动扶持」精神一致但数字无官方背书，标 **NEEDS VERIFICATION**。
- 真正高置信的事实（如抖音 2025 创作者大会四大计划、小红书社区公约 2.0、YouTube「发布频率/订阅数非排名信号」）均有官方通稿或工程博客支撑，应作为产品判定的优先依据。

**结论**：通用方法（目标设定、选题逻辑、复盘循环、信息雷达）跨平台适用；但推荐信号、内容形态、活动窗口、合规红线、变现路径必须平台化。产品上应允许「每个账号 × 每平台」持有各自的策略实例。

# 4. 成长阶段决定打法

同一账号在不同阶段，策略应不同（非死规则，而是阶段适配）：

- **冷启动期**：优先跑通「平台理解 + 内容-受众匹配」。重点：垂直统一、稳定更新、吃搜索/铁粉红利、不跨界打乱标签。抖音有新人保护期（前 5 作品），B站有暖冬计划（前 3 视频扶持），小红书/抖音对素人/新号有流量平权。
- **增长期**：放大已验证的有效内容类型，建立栏目化/系列化（提升复访与铁粉），开始参与平台活动，测试发布时间。
- **稳定期**：形成稳定 Content Mix 与节奏，深耕高价值用户（私信/社群），做商业化试探（蒲公英/花火/橱窗/商单）。
- **转化期**：以业务目标反推内容，把流量引向留资/成交/关注，强化搜索长尾与 evergreen 内容。

阶段不是线性终点，而是**可回退、可并行**的状态；产品应让 AI 基于数据判断阶段，而非让用户手动选。

# 5. 可持续进化的核心：策略不是一次性设定

本研究最反对「固定经营手册」。正确形态是：

```
当前策略 (CURRENT STRATEGY)
   ↓ 编译为 Operating Rules
执行 (EXECUTION)
   ↓
观测 (OBSERVATION)
   ↓
学习 (LEARNING)
   ↓
策略提案 (STRATEGY PROPOSAL)
   ↓ CEO 决策（必要时）
更新策略 (UPDATED STRATEGY)
```

策略从「行业经验初版」起步，经运行→收数据→判断效果→调整→形成「这个账号自己的方法」。避免一次表现好就永久改策略（相关≠因果，需观察窗口+重复证据+小实验）。详见 Doc6 与 Doc7。

# 6. 通用经营方法（跨平台骨架）

无论平台，成熟经营都包含以下循环组件：

1. **Goal（目标）**：账号为何经营，主/次目标。
2. **Intelligence（情报）**：持续观察平台政策、热点、竞品、用户信号（见 Doc2）。
3. **Strategy（策略）**：本账号的选题方向、Content Mix、平台优先级、增长假设。
4. **Operating Rules（运营规则）**：策略编译成的可执行日常规则（频率、时间窗、扫描计划）。
5. **Execution（执行）**：制作、发布、互动。
6. **Feedback（反馈）**：数据 + 用户信号回流。
7. **Learning（学习）**：判断什么有效、什么无效。
8. **Strategy Evolution（策略进化）**：微调或重大调整。

这八步是 Doc7 收敛框架的基础。

# 7. 多平台经营的「共享 vs 分化」原则

一个经营方向同时运营抖音/小红书/B站/TikTok/YouTube 时：

- **可共享**：经营方向、目标、情报雷达、选题池、核心素材（脚本/数据/观点）、品牌语言。
- **须重制**：成片形态（竖短 vs 横中长 vs 图文）、钩子与节奏、合规标注、标题关键词、互动方式。
- **须 FULL divergence（完全分化）**：当平台用户意图、内容生命周期、算法信号差异足够大时（如小红书重搜索长尾与种草、B站重深度与社区、TikTok 重完播与复看、YouTube 重 watch time% 与跨格式飞轮），不应强行群发同一成片。
- 避免用工程术语定义「复用规则」，但业务上要明确：基础素材可复用，成片必须平台化再创作。

# 8. 成本纪律（贯穿全文）

社媒运营极易变成无限 Token 黑洞。必须自始贯彻（详见 Doc2 第十八节）：
- 不无限扫描全网，建立 Source Registry。
- 分级扫描频率、RSS/API/结构化数据优先。
- 先轻量筛选再深度阅读、去重、只深挖高潜信号。
- 历史内容缓存、同类来源合并、低价值源降频。
- Task-scoped Context、知识按需读取。

以下问题留给产品设计专家在转化时判断，本研究只定义「业务需要什么能力」：

# 10. 本文件结论（一句话）

社媒持续增长的本质，是**以明确业务目标为锚、以情报系统为眼、以可进化的策略为脑、以平台差异为形**的长期经营循环；它拒绝死规则、拒绝群发、拒绝虚荣指标，依赖「运行—观测—学习—调整」的飞轮持续逼近「这个账号自己的最优经营方法」。
