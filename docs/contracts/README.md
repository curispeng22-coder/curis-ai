# Curis Contracts Index

Status: Phase-3.5 Research -> Decision -> Contract output

Contracts are the only bridge from research decisions to future development issues.

Rule:

```text
Research -> Decision -> Contract -> Issue -> Development
```

No feature may enter development unless its issue cites:

- relevant competitor research
- relevant domain research
- `docs/research/decisions/adopted-patterns.md`
- the matching contract file

## Contract Files

- `company-template-contract.md`
- `department-template-contract.md`
- `employee-template-contract.md`
- `workflow-template-contract.md`
- `capability-type-contract.md`

## Boundary

These contracts do not approve implementation by themselves. They define fields, source ownership, phase status, and Admin/Workspace boundaries for future issues.
