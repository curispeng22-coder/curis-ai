# 新团队启动交接

## 产品研究席

接收：产品方向问题和研究主题。
首项任务：只整理当前产品进度、架构和工作流的事实差距。
输出：事实、证据路径、未决问题。不得写 Issue。

## 产品规划席

接收：研究席结论和总负责人统一意见。
首项任务：建立“产品整体复盘与工作流重建”主 Issue。
输出：目标、范围、验收标准、负责人和 Next Seat。

## 项目调度席

接收：已批准 Issue。
首项任务：建立单主任务看板和席位交接记录。
输出：当前状态、阻塞、下一席位。

## 架构边界席

接收：规划席批准的架构问题。
首项任务：核对现有架构与主 Issue 的边界，不实施代码。
输出：允许范围、禁止范围、技术风险。

## 文档治理席

接收：本目录与 `docs/team-v2/LEGACY_RULES_AUDIT.md`。
首项任务：逐项清点旧规范，只输出分类，不删除文件。

## 系统交付席 / 质量运行席 / 安全边界席

当前等待对应 Issue，不主动启动新任务。
