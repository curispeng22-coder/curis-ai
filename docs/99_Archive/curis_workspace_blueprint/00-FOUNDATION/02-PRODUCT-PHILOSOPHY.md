# Product Philosophy

Status: Deprecated

## 1. Company First, Not Chat First

The first object is the company, not a chat session.

The user opens Curis Workspace to operate a company, not to talk to a model.

## 2. User Is CEO

The user manages goals, decisions, business direction, approvals, and final judgment.

AI employees execute work.

## 3. Employees Before Models

The user should create or recruit an employee first, then configure the employee's model policy.

Agent is the employee's role definition.
Model is the employee's ability resource.
Tools are the employee's equipment.
Knowledge is the employee's memory and reference base.
Workflow is the employee's operating procedure.

## 4. Capability Provider, Not Feature Ownership

Curis Workspace should not rebuild mature business tools.

It should integrate and orchestrate external and internal Capability Providers, such as GitHub, Obsidian, CapCut, browser automation, FFmpeg, Google Drive, WeChat Official Account, Xiaohongshu, Douyin, brokerage data, and e-commerce platforms.

## 5. Cost-Aware AI Operations

The system must help the user use the right model for the right task.

Expensive models should be used only where they create value. Lower-cost models should handle routine, structured, or low-risk work.

## 6. Workflow Over Prompt

The product should not center around prompt collections. It should center around repeatable business workflows and SOPs.
