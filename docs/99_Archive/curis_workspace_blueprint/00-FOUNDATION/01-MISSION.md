# Mission

Status: Deprecated

Curis Workspace helps solo entrepreneurs build a complete one-person company based on their own business goals, resources, skills, and budget.

The user acts as CEO. Curis Workspace manages the AI company structure.

## Mission Pillars

1. Help the user define business scopes.
2. Help the user create departments for each business scope.
3. Help the user recruit AI employees for each department.
4. Help the user assign workflows, tools, knowledge, and model resources to each employee.
5. Help the user control AI cost by assigning the right model to the right task.
6. Help the user operate multiple business directions from one platform.
