# Design Principles

Status: Deprecated

1. The user manages employees, not models.
2. The user operates a company, not a chat app.
3. Every feature must belong to Company, Business Scope, Department, Employee, Project, Workflow, Capability, Provider, Knowledge, or Budget.
4. Do not rebuild mature professional software unless integration is impossible.
5. Prefer orchestration over replacement.
6. Hide AI technical terms from normal users where possible.
7. Always expose cost visibility.
8. Every workflow should support human approval before risky actions.
9. Documents are the source of truth before code.
10. MVP must prove daily usage before pursuing ecosystem features.
