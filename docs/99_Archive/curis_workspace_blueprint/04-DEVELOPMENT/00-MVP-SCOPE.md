# MVP Scope

Status: Deprecated

## MVP Goal

Prove that a solo entrepreneur can create a company, select business scopes, recruit AI employees, assign model/tool/knowledge resources, and run basic workflows from one platform.

## MVP Includes

1. Company creation
2. Business scope selection
3. Department generation
4. Employee creation
5. Employee model policy
6. Capability provider registry
7. Basic AI chat through employee
8. Project creation
9. Knowledge source connection: local Markdown / Obsidian folder
10. Basic cost tracking

## MVP Excludes

1. Full marketplace
2. Team collaboration
3. Payment system
4. Fully automated publishing to all platforms
5. Advanced video editing
6. Full e-commerce automation
7. Advanced investment automation
