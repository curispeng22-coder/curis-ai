# Curis Workspace Blueprint V0.1

Status: Deprecated

Curis Workspace is a Personal Business OS for solo entrepreneurs. It helps one person build and operate an AI-powered company by organizing business scopes, departments, AI employees, workflows, knowledge, tools, models, and external platforms.

This folder is archived long-term blueprint material. It is useful for product vision and future roadmap discussion, but it is not the current implementation source of truth.

Current active source of truth:

- `AGENTS.md`
- `README.md`
- `docs/product/prd.md`
- `docs/pmo/current-status.md`
- `docs/sprints/mvp-implementation.md`

## Document Structure

- `00-FOUNDATION/`: product vision, mission, philosophy, principles, glossary
- `01-ARCHITECTURE/`: system architecture and domain model
- `02-PRODUCT/`: product modules and capability map
- `03-UX/`: user flows and information architecture
- `04-DEVELOPMENT/`: archived MVP scope and sprint plan
- `RESEARCH/`: competitor and reference research

because Phase 3-B1 does not migrate Decision Records.
