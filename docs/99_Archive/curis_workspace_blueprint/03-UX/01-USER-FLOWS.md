# User Flows

Status: Deprecated

## First-Time Setup Flow

```text
Create Company
  -> Choose Business Scopes
  -> Generate Departments
  -> Recommend Employees
  -> Connect Capability Providers
  -> Configure AI Budget
  -> Create First Project
  -> Start Operating
```

## Recruit Employee Flow

```text
Choose Department
  -> Choose Position
  -> Define Responsibilities
  -> Select Skills
  -> Assign Tools
  -> Assign Knowledge
  -> Configure Model Policy
  -> Set Budget
  -> Activate Employee
```

## Execute Workflow Flow

```text
Choose Project
  -> Choose Workflow
  -> Assign Employees
  -> System selects models and tools
  -> Employees execute tasks
  -> Human review
  -> Publish / Commit / Export / Save
  -> Log result and cost
```
