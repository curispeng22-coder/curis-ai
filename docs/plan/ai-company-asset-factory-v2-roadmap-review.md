## 2. 缺失资产

**2.1 员工资产升级（重点 2）**
现状：`et_*` 通过 `persona_ref` 指向 `pt_*`，而 `pt_*` **已**承载性格、沟通方式、汇报方式、决策/协作风格。所以「性格/沟通/汇报」不是从零缺，是已有但不够。
真正缺三样：
- **① 形象（Image/Identity）**：完全空白。没头像、没名字、没一致视觉身份，用户分不清「后端工程师」和「架构师」，谈不上把 AI 员工当数字同事。
- **② 每员工个性化覆盖**：现在 6 个员工基本「角色→原型」1:1 套用，backend/frontend 甚至共用 `pt_direct_executor`，没有「同原型、不同员工微调」。
- **③ 汇报关系/渠道**：员工模板没有「向谁汇报、走什么渠道」字段。

**建议（不触发 L2）**：把「形象」作为 `pt_*` 的新字段（头像/昵称/身份描述），`et_*` 加 `persona_overrides`（每员工可覆盖性格/沟通/汇报）。**不要**把形象独立成第 11 类新资产——否则触 L2 #7，没必要。

**2.2 Skill 资产体系（重点 3）**
现状：Skill 在契约里是核心资产，但真实内容只有 3 个通用行，研发线要用的 `skl_ai_rd_*` 全悬空。即使补齐，还缺一套管理机制：
- **生命周期**：无 draft→review→active→deprecated 状态机。
- **版本**：有 `version` 字段但无版本策略。
- **分类**：未按领域/类型归类，无法检索、无法按公司类型推荐。
- **默认绑定**：`et_*` 写死 `default_skill`，但「员工/部门/出厂包默认带什么」无统一规则，易断链。

**2.3 外部能力吸收（重点 4）— 触发 L2**
路径：外部 Agent → Skill（`skl_external_*`）/ Workflow（`wl_external_*`）；组合 → Department Template / Company Package；人设 → Employee Template + Persona。
**必须标 L2**：接入外部能力 = 接入外部服务/新能力来源，触 ③ 新市场方向，若对外提供触 ④ Marketplace，权限/隔离变化触 ⑤ 权限边界。**只给规划框架，不自己定怎么接。**

**2.4 Business Package 升级（重点 5）— 触发 L2**
现状：dashboard 已画好内容/商业公司驾驶舱，但 `ccp_ai_content_company`/`ccp_ai_commercial_company` **空壳连 seed 都没有**；对应 `ct_*`/`dt_*`/`et_*`/`skl_ai_commercial_*` 全空。（好消息：`wl_ai_content_*`/`wl_ai_commercial_*` 已 seed，workflow 内容反而最齐。）
**必须标 L2**：未来「售卖三类 AI 公司」= ① 商业模式变化 + ② 收费规则变化，强依赖冻结的 `cmcf_*`。**只评估要哪些资产，绝不规划收费细节。**

**可在已批准方向内自主推进（不用等总控）**

- `skl_*`/`tl_*`/`wt_*` 内容补齐与 `wl_*` 链路打通。

**须 L2 Gate / 总控裁定后才能动（本次只规划，不动手）**
- 任何「售卖三类 AI 公司」相关的包/模板/技能内容补全 → L2 #1/#2/#3。
- 任何外部 Agent / 第三方能力接入与吸收 → L2 #3/#4/#5。

- 任何因默认绑定导致员工**自动获得能力/权限**的变化 → 重评 L2 #5/#6。

## 6. 资产质量标准（「什么算一个资产真正完成」）

一个资产要判为「完成」，必须**全部**满足（任一不满足 = 空壳，禁止声称就绪）：
1. **有真实内容行**：数据库里有这条 seed 数据，不只是表结构/端点/引用存在。
2. **内容非空非占位**：描述不是 TBD、JSON 不是 `[]`/空对象；CEO 读得懂「这资产是干嘛的」。
3. **下游引用全闭环**：它引用的所有 id 都真实存在——`et_→pt_/skl_/tl_`、`wl_→wt_`、`ccp_→ct_/dt_/et_/pt_/skl_/tl_/wl_` 无一悬空。
4. **有版本与状态**：`version` 非空、`status=active`。
5. **被上层装配**：至少被一个 Package 或 Template 真实引用，不是孤儿。
6. **通过内容评审**：人话可读、可溯源到规划、无编造 id。
7. **对 Skill/Tool/Workflow**：有可执行的真实定义（技能有指令、工具可调、workflow 有步骤），不只名字。

> 回看：`skl_*`/`tl_*`/`wt_*` 在 1/2/3/7 全部不及格 → 判为空壳；`wl_*` 在 3 不及格（悬空）→ 判「有内容但未完成」。
