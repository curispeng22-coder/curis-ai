# Curis Asset Governance Foundation

Status: Frozen

Current Stage: Foundation Defined

Implementation: Deferred

## 一、项目定位

Curis Asset Governance 是 Curis 产品的未来基础能力。

本文仅冻结未来能力的基础原则与启动条件，不是当前开发规范。

## 二、基础原则（冻结）

1. 任何业务对象只能存在一个 Current。
2. 任何 Agent 默认维护 Current，不得创建平行资产。
3. 所有资产必须具有统一命名规范。
4. 所有 Revision 必须可追溯。
5. 设计图、设计规范、原型等属于同一资产包，必须同步维护。
6. 资产属于 Project，而不是 Agent。
7. Agent 是 Contributor，不是 Asset Owner。

## 三、不在本阶段实现

- Runtime
- API
- Database
- Workflow
- UI
- 自动命名
- 自动 Revision
- 自动审批

以上实现全部延期。

## 四、启动条件（Activation Conditions）

- [ ] Curis Engineering Convention v1.0 已正式冻结
- [ ] Curis MVP 已完成
- [ ] 多 Agent 协作成为日常开发方式
- [ ] Asset 数量达到需要自动治理的规模
- [ ] 人工维护 Current / Revision 已开始影响开发效率
