# Curis 新团队工作流 v2

## 主流程

```text
总负责人/参谋官
→ 产品研究席
→ 产品规划席
→ 项目调度席
→ 架构边界席
→ 系统交付席
→ 质量运行席
→ 产品规划席确认
→ 总负责人汇报
```

安全问题直接转安全边界席；文档问题直接转文档治理席。

## 单任务规则

- 一个席位只承担一个职能。
- 一个 Issue 只允许一个主要目标。
- 同时只运行一个主任务；验证任务由质量席单独接手。
- 未完成交接前，不启动下一席位任务。
- 不以“已讨论”代替 Issue、提交或 Review 证据。

## 状态规则

`未开始 → 实施中 → 待验证 → 已验证 → 已接受`

没有证据不得进入下一状态。

## 接管规则

新任务只读取 `knowledge/NOW.md`、当前角色说明、当前 Issue、最近 Review 或交接单。旧会话不自动载入。
