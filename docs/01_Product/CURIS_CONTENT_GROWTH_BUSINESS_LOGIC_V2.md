# 1. 六项补推（每项：为什么 / 输入 / 产出 / 谁负责 / 前一步 / 下一步 / 经营选择 / 多平台多账号变化 / 失败）

## 1.1 平台经营策略

**为什么需要**：一人业务产能有限，不可能所有平台原生深耕。选哪些平台、每个平台承担什么、投多少，是打法落地的第一个决定。没有这层，就会"每个平台都发、每个平台都半途而废"或"什么火追什么"。
**输入**：目标与成功定义（要触达谁、要什么结果——认知/线索/信任）；打法（主题与形态）；产能（能支撑几条生产链）；平台事实（受众画像/内容形态/规则波动/竞争强度）。
**产出**：平台组合——每个入选平台一条角色说明：承担什么经营目标（小红书=精准获客主阵地、抖音=品牌声量、公众号=深度信任与线索沉淀）、投入级别（主阵地/辅助/试验）、内容形态承诺、期望节奏；以及明确的"现阶段不做哪些平台"。
**谁负责**：Leader 拟（打法层）；**新增/退出平台改变投入方向，须 CEO 确认**。
**前一步**：Strategy。**下一步**：账号组建（每平台建号）与平台特有生产链。
**经营选择**：①深耕单平台 vs 多平台并进（产能约束：每多一个原生平台生产成本近似翻倍）；②**同内容分发 vs 各平台原生经营 vs 混合**——现实是主平台原生深耕、次平台适配分发、试验平台低投入试水；③组合调整触发：持续跑输角色预期 / 新平台机会 / 产能变化。
**多平台多账号变化**：组合策略本身就是多平台决定；平台内账号数量是下一层（账号经营）的事。
**失败/效果不好**：某平台长期达不到角色预期 → 换内容方式 / 降角色（主→辅）/ 暂停休眠（保留账号与历史，回收产能）→ 组合变更须 CEO。

## 1.2 平台特有内容生产链

**为什么需要**：不同平台的形态、语感、生产动作完全不同；统一写成"文案→视觉"会丢掉真实步骤（抖音的剪辑配音、公众号的排版、小红书的封面标题体系）。
**输入**：选题+Brief+素材；平台规则与语感。**产出**：该平台可直接发布的成品。**谁负责**：承担生产责任的员工（可一人走完整链——责任集中；也可分段多人协作）；责任归属随经营调整。**前一步**：选题/Brief/素材。**下一步**：审核→发布。

三条现实链：
- **小红书（图文，图为中心）**：笔记策划 → 正文文案（短、口语、平台语感）→ 封面图（首图决定点击）+内页图 → 标题（短、含搜索关键词）→ 标签/话题 → 合规检查 → 成品。
- **抖音（视频，制作最重）**：脚本（前 3 秒钩子/节奏/时长）→ 拍摄或素材混剪 → 剪辑（字幕/BGM/节奏）→ 配音 → 封面+标题 → 合规检查 → 成品。
- **公众号（长文）**：大纲 → 长文写作 → 插图 → 排版（编辑器样式）→ 标题+摘要+封面 → 合规检查 → 成品。

**通用 vs 特有**：通用=选题、Brief 要求、品牌口径、素材引用、合规检查、发布、数据、复盘；平台特有=上列中段步骤。
**生产链的完整形态（修正）**：**Topic / Content Intent → Platform Content Form → Account Context → Final Content Variant**。Platform 决定：内容形态、平台规则、尺寸、时长、发布格式——即"怎么适配这种媒介"；Account 决定：定位、目标受众、语气、内容结构、账号策略、当前经营阶段——即"以谁的身份、对谁、怎么表达"。例：同样小红书，Curis 官方账号与创始人 IP 账号虽 Platform 相同，最终 Content Variant 应当不同。
**一个选题→多平台版本的两种真实模式**：A **原生并行**（共享选题意图与素材，各平台按自己链条独立生产——平台差异大时用）；B **母内容拆解**（先深度长文→拆图文要点→再改口播脚本，"一鱼多吃"——同主题多形态覆盖时效率高）。选择由内容类型与平台组合策略决定。
**经营选择**：生产顺序（先主平台后分发 vs 并行）；环节外包（剪辑外包 vs 内部）。
**多账号变化**：生产链的**形态与规则是平台级**的（小红书图文、抖音视频）；**定位、受众、语气、内容结构与经营阶段是账号级**的——同平台不同账号按各自 Account Context 产出不同版本。
**失败**：某环节产能不足（剪辑瓶颈）→ 调整分工或减平台；成品质量不稳→模板与规范（见 1.3）。

## 1.3 内容与素材资产

**为什么需要**：内容业务会积累大量可复用资产；没有资产意识→每次从零找图、风格漂移、版权风险、爆款经验无法复用。
**素材来源**：①自制（拍摄/录屏/截图）②AI 生成（图像工具产出）③外采授权素材（可商用图库）④历史内容（旧笔记翻新、爆款结构拆解）⑤用户内容（UGC，需授权/脱敏）⑥竞品与行业参考（**只参考思路，不搬素材**——版权红线）。
**进入生产**：Brief 引用素材与模板 → 生产者取用。**品牌素材**：logo/品牌色/字体/封面模板/口播开场——一致性的保证。
**历史内容复用**：数据好的旧内容做更新版/续集；爆款结构固化为模板。
**模板复用**：封面模板、脚本结构模板、排版模板——模板是"可复用的生产模式"，是实验结论（1.5）的固化处。
**一份素材多用**：一张产品截图服务多篇笔记；一段出镜素材进多条视频。
**成品↔素材关系**：**双向资产网络**——素材→成品（加工）；成品→素材（旧内容翻新、爆款片段二剪）。成品定稿即归档（治版本混乱）。
**谁负责**：视觉员工管视觉资产与模板；全员引用；Leader 定品牌规范与版权红线（红线属于目标定义的约束）。
**前一步**：Brief（需要什么）。**下一步**：平台生产链（取用）。
**经营选择**：资产库建设深度（轻：随用随收 vs 重：结构化标签库）——随规模演进，不预设。
**多平台多账号**：各平台规格不同（尺寸/时长）→素材按规格派生；模板按平台分套；品牌口径跨平台统一。
**失败/风险**：版权（无授权素材）→红线约束+发布前检查；版本混乱→定稿归档；风格漂移→模板与规范。

## 1.4 账号持续经营（本轮核心：账号 = 长期经营单元）

**4.1 账号是什么**：不是"发布目标"。每个自有账号都是内容生意里的**长期经营单元**：有自己的定位（在人设/领域上"是谁"）、受众（该号触达谁）、策略（内容结构配比、节奏、语感）、内容历史、发布节奏、经营状态、数据、互动、Learning、下一周期。同一业务下多个账号是**不同的经营单元**（官方号=专业产品视角；人设号=轻松科普），不是同一内容的多处转发。**Platform 不是 Workspace，Account 也不是 Workspace**——两者都是被经营的经营事实/单元，不是经营环境容器。

**4.1A 经营层级（Business → Platform → Account）**：
```
Business Strategy        → Content Growth 整体怎么增长（主题/形态/取舍/平台组合）
→ Platform Strategy      → 为什么经营这个平台；这个平台在整体业务中承担什么角色
→ Account Strategy       → 这个具体账号是谁、服务谁、发什么、什么节奏、用什么语气与内容结构
→ Account Operating Cycle → 生产 → 发布 → 数据 → 互动 → Learning → 调整 → 下一周期
```
四层各答各的问题，不可互相替代：Business 层换打法会影响全部平台；Platform 层调角色只影响该平台；Account 层调策略只影响该账号。

**4.2 账号级经营循环（即 Account Operating Cycle）**（业务循环缩小一号，在每个账号上独立运转）：
```
账号定位/受众 → 账号策略（内容结构+节奏+语感）→ 本账号周期内容
→ 生产（平台链，按本账号 Account Context：定位/受众/语气/结构/阶段）→ 本账号发布 → 本账号回执
→ 本账号数据与互动 → 本账号 Learning（"这个号的观众吃这套"）
→ 账号策略/计划调整 → 下一周期
```
**业务循环与账号循环的关系**：业务周期计划把内容**分配**到各账号（组合）；各账号独立执行并形成**各自的反馈**；业务级复盘做**跨账号**比较与取舍（哪个号加码、哪个降级）。同一 Content 可分发到多账号，但 Publication 之后反馈、互动、Learning 按账号各自累积——**不存在"跨账号合并成的一条数据"**，只有各账号自己的事实；业务级比较是把各账号事实放在一起看，不是合并成一个数。
**每个 Account 必须有明确的经营责任归属**（修正，替换原"每账号必须有负责人"）：责任可以——由 Business Leader 直接承担；由一名员工承担该账号的多项责任（内容/发布/互动/分析中若干项）；由多名员工分别承担不同责任。**重点是账号不能处于"没人负责"的状态，但不强制 Account→单一负责人**。账号出入组合、封禁等重大事项到 CEO。

**4.3 定位/受众/策略/结构/节奏**：定位=这个号"是谁"；受众=画像；策略=内容结构配比（如 60% 干货/30% 案例/10% 热点）+发布节奏（每周几篇/几点）+语感（严谨/轻松）。**差异化**：同平台矩阵号必须定位区隔（防自我竞争）；跨平台可同定位不同形态。

**4.4 成长阶段**（阶段决定打法）：新号冷启动（前 2–4 周：验证方向、求基线、不追爆款、不宜重投入）→ 成长期（找到有效模式→放量+稳节奏）→ 成熟期（稳定产出+精细化+商业化准备）→ 衰退/转型（长期下滑→转型或休眠）。

**4.5 账号异常**：限流（数据骤降但无违规通知、原因不明→排查实验）；违规（平台通知→整改）；封禁（最严重：经营暂停、内容资产保留、CEO 关切——不可逆损失，考虑新号或迁移）。

**4.6 表现下降排查**：先判断范围（全行业/全平台下滑 vs 仅本号）→ 内容质量？频率？形式？限流？→ 小步调整（连实验）→ 持续下降→账号策略级调整（结构/节奏/定位）→ 再不行→降角色或休眠（连平台组合）。

**4.7 多账号协同**：差异化（防同质自我竞争）；协同（合规前提下互相导流、同一热点多号不同角度、跨平台引用）。

**经营选择**：人设统一 vs 矩阵差异化；冷启动（先验证后放量 vs 铺量试错——现实推荐前者）；频率（产能内）。
**失败**：见 4.5/4.6；最坏结果是封禁（资产损失）——所以合规红线与发布前检查必须在前。

## 1.5 增长实验

**为什么需要**：内容增长的本质是持续试错；不实验就只剩随机波动。
**真实形态**：标题实验（同内容两版标题）；封面实验；内容形式实验（图文 vs 视频、干货 vs 故事）；发布时间实验；平台实验（组合里的试验位）；账号策略实验（人设/栏目调整）。
**完整过程**：提出假设（"封面带大字点击率更高"）→ 设计对照（同期同类内容两版封面；**多数平台无原生 A/B，现实是跨内容对比**）→ 执行 → 收数据（足够样本/时间窗）→ 判断（显著还是噪声；**样本不足不下结论**）→ 结论写入 Learning → 固化（模板/结构/节奏更新）→ 影响下一轮。
**业务纪律**：①实验要有假设与判断标准，否则是乱试；②样本不足标"不确定"，可延长或放弃；③主阵地保持稳定产出，实验放次要账号/时段（别把主业当实验田）；④结论按其范围落地（账号级结论不自动全局化——与 1.4 账号 Learning 分层一致）。
**谁负责**：Leader/策划提出；执行随生产；判断靠数据；结论落地走 Learning 链。
**输入**：数据/竞品观察/灵感。**产出**：实验记录（假设/设计/结果/结论）→Learning。
**前一步**：复盘或数据发现"值得验证的问题"。**下一步**：Learning→策略/账号/模板调整。
**经营选择**：正式对照实验 vs 经验尝试（"这期试试新形式"）——现实多为后者+跨内容对比；两者都合法，区别是**结论可信度标注**。
**多平台多账号**：跨平台数据不可比→实验通常单平台内做；结论跨平台迁移谨慎。
**失败**：无结论→标不确定；假设被证伪→也是有效 Learning（避免重复犯错）。
**结论**：业务逻辑层**不需要独立"实验系统"**——实验="有假设的 Work+有对照的判断+进 Learning 的结论"。

## 1.6 周期性内容规划

**为什么需要**：Strategy 与单条 Topic 之间缺一层：这一段时间具体做什么、够不够、偏不偏。没有它→每天临时想选题（断更）、结构失衡（全是热点没干货）、产能与目标脱节（月涨 1000 粉但周产 1 篇）。**判断：这是不可缺少的一环**——它把打法执行化、是选题的来源、是库存的治理者。
**层次**：月度目标（本月涨粉 1000/出 15 篇）→ 周内容计划（本周 3 篇：2 干货 1 案例）→ 平台内容组合（小红书 3+抖音 2，各什么类型）→ **选题库存**（已储备未生产，安全水位防断粮）。
**输入**：Strategy；上周期数据（哪类有效）；各账号内容结构配比；产能。**产出**：周期计划+库存水位。
**谁负责**：Leader 主持（选题会=计划会，TIME 动力）；执行者认领。
**前一步**：Strategy+上周期复盘。**下一步**：选题→生产→发布。
**经营选择**：刚性 vs 留机动位（现实：计划为底+热点插队）；周期粒度（周计划为主、月度定目标）；库存策略（常备 N 篇安全线——连 STATE 动力）。
**多平台多账号**：计划按平台/账号分配内容组合；各账号节奏在账号策略里，组合在计划里。
**失败/调整**：计划完不成（产能不足→降目标或加资源）；某类内容证伪→计划结构调（Learning→Plan→Strategy 传导）；计划本身复盘（达成率）。

# 2. 完整经营链重走（V2 全链）

```
商业意图
→ 0  Goal / 成功定义（含约束：品牌口径、版权红线、预算上限、停止条件）
→ 1  Strategy（主题/形态/取舍）
→ 2  平台组合策略（每平台角色与投入；不做什么平台）
→ 3  经营责任分配（研究/策划/生产/视觉/发布/分析必须有人承担；可一名员工全担、一名员工多项、多名员工分摊；随经营随时调整——**业务步骤固定，责任分配可变，员工数量不决定业务结构**）
→ 4  周期性内容规划（月度目标 → 周计划 → 平台/账号内容组合 → 选题库存安全水位）
    ↑ 喂入：信号收集 + 竞品研究 + 上周期 Learning
→ 5  选题（计划+信号+研究）
→ 6  Brief → 7 素材/模板取用 → 8 平台特有生产链（Platform Content Form × 各账号 Account Context）
→ 9  审核 / 政策（分档）
→ 10 发布到各账号 → 11 各账号回执
→ 12 各账号数据与互动（各自独立累积）
→ 13 分析（跨账号比较）+ 增长实验（假设→结论）
→ 14 账号级 Learning → 账号策略/计划调整 →（该账号下一周期）
→ 15 业务级复盘 Learning → Strategy / 平台组合 / 周期计划调整
→ 16 下一周期（各账号 + 业务）
```
