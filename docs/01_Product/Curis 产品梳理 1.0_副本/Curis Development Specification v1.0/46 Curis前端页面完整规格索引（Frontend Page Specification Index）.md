# Curis Development Specification

# 46 Curis前端页面完整规格索引（Frontend Page Specification Index）

版本：v1.0-draft

---

# 1. 文档定位

本章节用于定义：

Curis Desktop 前端页面体系。

目标：

让前端开发、UI设计、AI开发Agent明确：

- 页面有哪些；
- 页面职责是什么；
- 页面之间如何关联；
- 哪些页面当前开发；
- 哪些页面未来扩展。

---

# 2. 页面设计原则

Curis页面不是传统后台。

核心：

```
用户目标

↓

业务场景

↓

AI员工协作

↓

任务执行

↓

成果
```

---

# 3. 一级页面结构

Curis Desktop：

```
首页

项目

会议室

组织中心

能力中心

资料中心

成果中心

数据洞察

经营分析

设置
```

---

# 4. 全局组件

所有页面共享：

---

## AI秘书

功能：

- 全局入口；
- 当前上下文理解；
- 操作辅助。

---

## 全局搜索

搜索：

- 项目；
- 员工；
- 任务；
- 成果；
- 知识。

---

## 能力切换器

位置：

工作现场。

---

功能：

快速切换：

- 工作模式；
- Agent；
- Model；
- Capability Profile。

---

## 通知中心

展示：

- 任务完成；
- 风险提醒；
- 异常。

---

# 5. 首页（Home）

定位：

AI公司驾驶舱。

---

主要模块：

```
AI秘书摘要

待决策事项

重点项目

最近成果

经营摘要

任务状态
```

---

用户目标：

快速知道：

发生什么。

需要做什么。

下一步是什么。

---

# 6. 项目中心（Projects）

定位：

管理所有业务项目。

---

页面：

## 项目列表

功能：

查看。

筛选。

创建。

---

## 创建项目

流程：

```
选择模板

↓

配置团队

↓

配置能力

↓

生成项目
```

---

## 项目详情

展示：

- 项目目标；
- 团队；
- 状态；
- 成果。

---

# 7. 项目工作台（Project Workspace）

定位：

项目执行中心。

---

结构：

```

任务

资料

成果

数据

```

# 9. 组织中心（Organization）

---

