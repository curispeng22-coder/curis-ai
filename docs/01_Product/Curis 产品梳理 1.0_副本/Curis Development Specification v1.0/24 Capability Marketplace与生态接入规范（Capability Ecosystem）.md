# Curis Development Specification

# 24 Capability Marketplace与生态接入规范（Capability Ecosystem）

版本：v1.0-draft

---

# 1. 系统定位

Capability Ecosystem 负责构建 Curis 的能力生态。

目标：

让 Curis 不局限于自身开发能力。

支持：

- 第三方模型；
- 第三方Agent；
- 第三方Skill；
- 第三方Tool；
- 第三方Workflow；
- 企业私有能力。

---

# 2. 核心理念

Curis不生产所有能力。

Curis负责：

发现。

管理。

组合。

调度。

治理。

---

关系：

```
外部能力

↓

Capability Marketplace

↓

Capability Registry

↓

智能调度中心

↓

项目执行
```

---

# 3. 能力生态结构

```
Capability Ecosystem

├── 用户自定义能力

├── 第三方开发者能力

├── 企业私有能力

```

# 本章冻结内容

本章定义 Curis 能力生态。

核心：

Curis不是封闭AI产品。

而是连接各种AI能力，并将其组织成可执行业务能力的平台。
