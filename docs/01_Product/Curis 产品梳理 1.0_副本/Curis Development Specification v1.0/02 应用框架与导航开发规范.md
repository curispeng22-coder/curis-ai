# Curis Development Specification

# 02 应用框架与导航开发规范（Application Shell & Navigation）

版本：v1.0-draft

---

# 1. 模块定位

应用框架是 Curis Desktop 的基础运行环境。

负责：

- 应用整体布局；
- 页面切换；
- 全局状态；
- AI秘书入口；
- 全局操作入口。

---

# 2. 应用结构

Curis Desktop 基础结构：

```
Application Shell

├── Sidebar
│
├── Top Bar
│
├── Main Content
│
├── AI Assistant Layer
│
└── Global Services
```

---

# 3. 页面布局

默认桌面布局：

```
┌──────────────────────────────┐
│ Top Bar                       │
├──────────┬───────────────────┤
│          │                   │
│ Sidebar  │ Main Content      │
│          │                   │
│          │                   │
└──────────┴───────────────────┘

             +
        AI秘书浮层
```
