# Curis Development Specification

# 04 项目中心开发规格（Project Center Specification）

版本：v1.0-draft

---

# 1. 页面定位

项目中心负责管理 Curis 中所有业务项目。

项目中心解决：

- 查看有哪些项目；
- 创建新项目；
- 管理项目生命周期；
- 快速进入项目工作区。

---

# 2. 页面目标

用户进入项目中心后，可以：

- 创建业务项目；
- 查找已有项目；
- 查看项目状态；
- 管理项目关系；
- 进入项目执行环境。

---

# 17. API需求

## 获取项目列表

```
GET /projects
```

参数：

department_id。

status。

template_id。

owner_id。

---

## 创建项目

```
POST /projects
```

输入：

template_id。

name。

objective。

owner_id。

---

## 获取项目详情

```
GET /projects/{id}
```

---

## 修改项目

```
PATCH /projects/{id}
```

---

## 生命周期

```
POST /projects/{id}/pause

POST /projects/{id}/resume

POST /projects/{id}/archive
```
