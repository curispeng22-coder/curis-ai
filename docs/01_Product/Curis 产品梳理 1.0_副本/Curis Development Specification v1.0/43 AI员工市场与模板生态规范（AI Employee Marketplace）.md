# Curis Development Specification

# 43 AI员工市场与模板生态规范（AI Employee Marketplace）

版本：v1.0-draft

---

# 1. 系统定位

AI员工市场用于扩展 Curis 的 AI员工生态。

目标：

让用户可以快速获得：

- 行业AI员工；
- 专业AI团队；
- 工作模式；
- 业务模板；
- 能力组合。

---

# 2. 核心理念

未来用户不一定需要：

从零创建AI员工。

---

类似现实世界：

招聘员工。

购买服务。

组建团队。

---

Curis支持：

```
发现员工模板

↓

安装

↓

配置

↓

加入组织

↓

执行业务
```

# 3. AI员工与Capability区别

需要明确：

## Capability

是能力。

例如：

Codex。

Git。

数据分析Skill。

---

## AI Employee

是业务角色。

例如：

研发负责人。

内容运营经理。

财务分析员。

---

关系：

```
AI Employee

↓

Capability Profile

↓

Capability

```
