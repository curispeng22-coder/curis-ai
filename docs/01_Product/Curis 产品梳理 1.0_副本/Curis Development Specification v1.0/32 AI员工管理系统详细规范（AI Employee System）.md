# Curis Development Specification

# 32 AI员工管理系统详细规范（AI Employee System）

版本：v1.0-draft

---

# 1. 系统定位

AI员工系统负责定义：

Curis中“谁负责什么工作”。

它不是：

- 一个聊天机器人列表；
- 一个Agent列表；
- 一个模型选择页面。

它是：

AI公司的组织执行主体。

---

# 2. 核心理念

Curis中的执行关系：

```
用户

↓

AI秘书

↓

负责人AI员工

↓

专业AI员工

↓

Capability

↓

成果
```

---

# 3. Employee与Agent区别

必须区分：

## AI员工（Employee）

负责：

- 理解业务目标；
- 管理任务；
- 维护上下文；
- 协调能力。

---

## Agent

负责：

- 执行具体动作。

---

例如：

```
研发负责人

(Employee)

↓

调用：

Codex Agent

Claude Code Agent

测试Agent
```

---

# 4. AI员工模型

Employee包含：

```
Employee

├── 基础信息

├── 角色定义

├── 职责

├── Memory

├── Capability Profile

├── 项目关系

├── 工作记录

└── 成果
```

---

# 5. 员工基础信息

组件：

EmployeeProfile

---

字段：

```
id

name

role

department_id

description

avatar

status
```

---

展示：

姓名。

岗位。

所属部门。

职责。

状态。

---

# 6. 员工角色定义

角色决定：

员工负责什么。

---

例如：

## 研发负责人

职责：

- 技术规划；
- 任务拆解；
- 协调开发；
- 质量控制。

---

## 内容负责人

职责：

- 内容策略；
- 生产管理；
- 数据分析。

---

## 行政助手

职责：

- 文件整理；
- 日程管理；
- 信息汇总。

---

# 7. 员工职责配置

组件：

EmployeeRoleConfig

---

配置：

## 工作目标

例如：

负责提高研发效率。

---

## 工作范围

例如：

负责研发部门项目。

---

## 禁止范围

例如：

不可访问财务资料。

---

# 8. 员工能力配置

组件：

EmployeeCapabilityProfile

---

员工不直接绑定大量能力。

通过：

Capability Profile。

---

例如：

研发负责人：

```
默认模式：

软件开发模式


包含：

开发Agent

Claude Code

Git Tool

测试Workflow
```

---

# 9. 员工Memory

员工拥有：

长期工作经验。

---

包括：

## 工作习惯

例如：

用户喜欢简洁方案。

---

## 专业经验

例如：

某类Bug解决方式。

---

## 历史项目经验

例如：

之前项目采用的技术方案。

---

# 10. 员工上下文

员工执行任务时：

加载：

```
员工Memory

+

项目Memory

+

任务Context

+

相关Knowledge
```

---

不是：

读取所有历史。

---

支持：

```
Waiting

Error
```

当前状态。

当前任务。

员工可以进入：

---

- 分析；
- 提供建议；

# 17. 员工自动学习

提取经验。

---

流程：

```

↓

结果分析

↓

经验提取

↓

Memory更新

↓

能力优化
```

# 18. 员工绩效分析

不是传统绩效。

而是：

运行效果分析。

---

指标：

- 完成任务数量；
- 成功率；
- 成本；
- 用户反馈；
- Memory增长。

---

# 19. 员工与智能调度

智能调度选择：

具体执行能力。

---

员工负责：

提出需求。

---

例如：

研发负责人：

需要：

代码修改。

---

调度：

选择：

Codex。

员工工作模式。

---

---

代码审查模式。

Tool。

# 23. 验收标准

AI员工系统完成后：

用户可以：

创建AI员工。

定义职责。

配置能力。

分配项目。

查看成长。

---

检查：

## 产品

是否像管理员工。

---

## 技术

是否支持不同Agent。

---

## 智能

是否支持Memory成长。

AI员工不是模型。

不是Agent。

而是：

拥有职责、记忆、能力和任务关系的数字员工。
