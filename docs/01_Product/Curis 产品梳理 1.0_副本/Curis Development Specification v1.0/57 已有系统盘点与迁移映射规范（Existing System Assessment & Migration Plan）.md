# Curis Development Specification

# 57 已有系统盘点与迁移映射规范（Existing System Assessment & Migration Plan）

版本：v1.0-draft

---

# 1. 规范定位

本规范用于解决：

Curis已有开发成果如何接入最终产品架构。

目标：

避免：

- 重复开发；
- 推翻已有代码；
- 架构冲突；
- 功能遗漏。

---

# 2. 核心理念

Curis后续开发不是：

```
重新开发一个新系统
```

而是：

```
已有系统

↓

映射产品架构

↓

补齐缺失能力

↓

统一入口

↓

形成Curis完整产品
```

---

# 3. 盘点原则

所有已有功能必须归类：

```
已完成

↓

部分完成

↓

需要重构

↓

暂不处理

↓

未来规划
```

---

# 15. 重构判断标准

满足以下情况：

需要重构：

---

## 违反核心架构

例如：

业务直接绑定模型。

---

## 无法扩展

例如：

新增Agent需要修改大量代码。

---

## 无法支持Memory/Context

例如：

上下文硬编码。

---

# 16. 不重构原则

不要为了：

“架构更漂亮”。

重写已有功能。

---

优先：

增加Adapter。

增加抽象层。

逐步迁移。
