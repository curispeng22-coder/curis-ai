# Curis Development Specification

# 06 组织中心开发规格（Organization Center Specification）

版本：v1.0-draft

---

# 1. 页面定位

组织中心负责管理 Curis AI 公司的组织结构。

核心对象：

```
Company

↓

Department

↓

Employee
```

---

组织中心解决：

- 公司如何组织；
- 部门如何划分；
- 员工如何管理；
- 员工如何参与业务。

---

# 2. 页面结构

```
Organization Center

├── 公司

├── 部门

└── 员工
```

---

# 3. 公司模块

组件：

---

## 3.1 页面目标

展示当前 AI 公司信息。

```
description

avatar

status
```
