# Curis Product Bible

# 03 信息架构

版本：v1.0-draft

---

# 1. 信息架构原则

Curis 的信息架构围绕业务对象组织，而不是围绕技术能力组织。

设计目标：

- 用户容易理解
- 页面职责单一
- 导航层级简单
- 支持未来业务扩展
- 支持 Workspace 与 Admin 拆分

---

# 2. 一级导航

当前版本采用以下一级导航：

1. 首页
2. 项目
3. 会议室
4. 组织中心
5. 能力中心
6. 资料中心
7. 成果中心
8. 数据洞察
9. 经营分析
10. 设置

一级导航尽量保持稳定。

新增导航应优先评估是否能够通过已有模块扩展完成。

---

# 3. 全局入口

以下功能不属于一级导航，而属于全局能力。

## AI秘书

定位：

全局智能助手。

支持：

- 当前页面上下文
- 当前项目上下文
- 当前会议上下文
- 当前资料上下文

支持：

- 文字
- 语音
- 文件
- 图片

交互形式采用桌面宠物模式，可自由移动。

---

用于展示：

- 普通通知
- 自动任务完成
- 系统提醒
- 能力状态变化

# 10. 产品边界

Workspace 负责：

- 创建和管理实际业务
- 调用能力
- 查看成果
- 查看经营数据

高级管理负责：

- 业务模板
- 能力目录
- Business Agent
- 治理规则

当前桌面版二者位于同一应用。

商业化版本拆分为：

Workspace

+

Admin

---

# 本章冻结内容

本章定义 Curis Desktop 的整体信息架构。

后续新增功能，应优先复用现有导航与页面，而不是增加新的一级导航。
