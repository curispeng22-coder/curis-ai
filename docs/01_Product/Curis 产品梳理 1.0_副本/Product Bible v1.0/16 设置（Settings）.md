# Curis Product Bible

# 16 设置（Settings）

版本：v1.0-draft

---

# 1. 页面定位

设置负责管理 Curis Desktop 的系统配置。

设置不是业务工作区。

业务管理：

进入：

- 项目
- 组织中心
- 能力中心
- 资料中心

设置负责：

- 系统配置
- 本地连接
- 高级管理
- 用户偏好

---

# 2. 页面结构

推荐：

```
设置

├── 基础设置
├── 账户设置
├── 通知设置
├── 预算设置
├── 数据设置
├── Local Bridge
└── 高级管理
```

---

# 8. Local Bridge

## 页面定位

连接本机能力。

---

Local Bridge 负责：

- 本地文件访问；
- Git访问；
- 项目目录访问；
- 本地命令执行；
- 本地工具连接。

---

# 8.1 连接流程

```
启动Local Bridge

↓

授权目录

↓

测试连接

↓

绑定项目

↓

开始使用
```
