# Curis Product Bible

# 11 能力中心（Capability Center）

版本：v1.0-draft

---

# 1. 页面定位

能力中心负责管理 Curis 可以使用的各种 AI 能力。

能力不是业务主体。

能力是：

员工完成工作的资源。

---

# 2. 核心关系

正确关系：

```
员工

↓

调用能力

↓

完成任务

↓

产生成果
```

而不是：

```
模型

↓

直接完成业务
```

---

# 3. 能力类型

能力中心统一管理：

## Model

模型能力。

例如：

- GPT
- Claude
- Gemini
- DeepSeek
- 本地模型

---

## Agent

外部或内部智能体。

例如：

- Codex
- WorkBuddy
- Claude Code
- 专业业务 Agent

---

## Skill

专业技能。

例如：

- 内容分析
- SEO分析
- 代码审查
- 数据分析
- 文案优化

---

## Tool

工具能力。

例如：

- 浏览器
- 文件操作
- 数据查询
- Git操作
- API调用

---

## Workflow

自动化流程。

例如：

- 每日热点分析
- 自动测试流程
- 发布流程

---

## MCP

外部能力连接协议。

用于：

- 工具发现
- 数据访问
- 外部服务调用

---

## Connector

外部系统连接。

例如：

- GitHub
- Notion
- 网盘
- 邮件
- 第三方平台

---

## Credential

认证信息。

例如：

- API Key
- OAuth
- Token

---

# 4. 能力来源

能力有两种主要来源。

---

# 4.1 平台提供能力

来源：

未来 Admin。

当前桌面版本：

由高级管理维护。

例如：

官方推荐：

- 模型配置
- Agent模板
- Skill包
- Workflow模板

---

# 4.2 用户自定义能力

用户可以添加：

- 自己的模型
- 自己的 Agent
- 自己的 Skill
- 自己的 Workflow
- 自己的 MCP

---

能力中心

├── 我的能力

类型

来源

状态

绑定对象

健康状态

成本信息

---

例如：

```
Claude Sonnet

类型：
Model

来源：
用户自定义

状态：
可用

绑定：
研发负责人

```

# 7. 平台能力

展示：

系统提供的能力。

例如：

推荐模型

业务 Workflow

行业模板能力

---

用户可以：

查看

启用

配置

绑定

# 8. 用户自定义能力

用户可以：

添加能力。

例如：

添加模型：

填写：

- 名称
- 服务商
- Model ID
- API地址
- Key

然后：

测试连接。

成功后：

加入能力池。

# 11. 能力选择策略

项目执行时：

系统根据：

任务类型

员工职责

能力状态

成本

成功率

权限

选择能力。

---

支持：

首选能力

备用能力

自动切换

---

例如：

研发任务：

首选：

Codex

失败：

切换：

Claude Code

---

# 12. 能力测试

每个能力支持：

连接测试。

执行测试。

---

例如：

模型：

测试：

是否可以正常回复。

---

Agent：

测试：

是否可以执行任务。

---

Tool：

测试：

输入输出是否正常。

---

# 16. AI秘书在能力中心

AI秘书可以：

帮助配置能力。

例如：

用户：

> 我要接入Claude。

AI秘书：

引导：

选择模型

填写Key

测试连接

绑定员工

---

AI秘书也可以：

分析：

当前项目缺少什么能力。

例如：

> 小红书项目缺少图片设计能力，是否添加？

---

# 17. 页面状态

支持：

暂无能力

添加能力

测试中

连接成功

连接失败

额度不足

权限不足

同步中

---

# 18. 页面原则

能力中心管理：

“有什么可以用”。

不是：

“业务怎么做”。

业务流程进入：

项目和业务模板。
