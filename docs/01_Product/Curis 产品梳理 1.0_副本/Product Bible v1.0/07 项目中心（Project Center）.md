# 07 项目中心（Project Center）

版本：v1.0-draft

---

# 1. 页面定位

项目中心负责管理整个 AI 公司的所有项目。

项目中心不是项目详情。

它负责：

- 创建项目
- 查找项目
- 管理项目
- 查看项目状态
- 快速进入项目工作区

项目真正执行发生在：

项目工作台。

---

# 2. 页面目标

用户进入项目中心，希望完成：

- 创建新项目
- 查看所有项目
- 找到重点项目
- 管理项目生命周期
- 查看项目整体情况

而不是：

具体执行任务。

# 20. 页面原则

项目中心负责：

管理项目。

项目工作台负责：

执行项目。

两者职责保持独立。
