# Curis Product Bible

# 06 首页（Home）

版本：v1.0-draft

---

# 1. 页面定位

首页是用户进入 Curis Desktop 后的默认入口。

首页的职责不是展示所有数据，而是帮助用户快速了解：

- 当前公司状态
- 当前需要处理的事情
- 当前重点项目
- 下一步建议

用户通常停留时间较短。

重点是：

> 快速理解，而不是深度操作。

---

# 2. 页面目标

首页主要解决四个问题：

1. 今天发生了什么？
2. 哪些事情需要我处理？
3. 当前重点项目有哪些？
4. 我下一步应该做什么？

首页不是：

Dashboard。

也不是：

经营分析页面。

也不是：

项目详情。

---

# 15. 推荐原则

首页优先展示：

真正需要处理的信息。

不是：

所有数据。

不是：

所有统计。

尽量减少：

大量数字

大量图表

大量技术信息

更多强调：

建议

行动

成果

# 17. 页面设计建议

推荐整体风格：

- 简洁
- 留白
- 信息层级清晰
- 一个视觉重点
- 减少装饰性元素

首页首先传达：

"今天应该做什么。"

其次才是：

"系统运行得怎么样。"

---

# 本章冻结内容

本章定义首页职责、信息结构与交互原则。

视觉设计、组件样式和具体布局可根据 Design System 演进调整，但页面目标和模块职责建议保持一致。
