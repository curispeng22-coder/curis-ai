# Curis Product Bible

# 01 产品定位

版本：v1.0-draft

------------------------------------------------------------------------

## 1. 产品名称

Curis Desktop

定位：

Personal AI Workspace（个人 AI 工作台）

------------------------------------------------------------------------

## 2. 产品目标

Curis 负责统一组织和管理 AI 工作，而不是替代各种 AI 能力提供者。

产品目标：

-   一个桌面应用完成全部 AI 工作
-   管理 AI 公司，而不是管理聊天窗口
-   将目标持续转化为成果
-   沉淀知识、经验和经营数据

------------------------------------------------------------------------

## 3. 产品边界

Curis 负责：

-   公司组织
-   部门管理
-   AI员工
-   项目
-   任务
-   成果
-   知识
-   经营

外部能力负责：

-   大模型
-   Agent
-   Skill
-   Tool
-   MCP
-   第三方平台

Curis 对外部能力进行统一组织、配置、调度和治理。

------------------------------------------------------------------------

## 4. 产品阶段

### 第一阶段

Curis Desktop

特点：

-   单机桌面应用
-   一体化产品
-   同时包含 Workspace 与高级管理能力
-   面向个人使用与产品验证

### 第二阶段

拆分：

-   Workspace
-   Admin

部署服务器。

### 第三阶段

商业化：

-   官网
-   多用户
-   模板市场
-   团队协作
-   生态开放

------------------------------------------------------------------------

## 5. 用户角色

当前版本：

用户同时承担：

-   CEO
-   管理员
-   产品负责人

AI承担：

-   部门负责人
-   项目负责人
-   AI员工

------------------------------------------------------------------------

## 6. 核心理念

用户面对的是：

公司 → 部门 → 员工 → 项目 → 任务 → 成果

而不是：

Model → Agent → Workflow

能力属于员工，不直接成为产品主对象。

------------------------------------------------------------------------

## 7. 成功标准

用户打开 Curis 后，应能够：

-   创建公司和部门
-   创建项目
-   调用 AI 员工执行工作
-   查看成果
-   查看经营分析
-   沉淀知识
-   持续优化 AI 公司

------------------------------------------------------------------------

## 本章冻结内容

本章定义产品定位与边界。

后续版本允许扩充，但不建议轻易改变产品定位。
