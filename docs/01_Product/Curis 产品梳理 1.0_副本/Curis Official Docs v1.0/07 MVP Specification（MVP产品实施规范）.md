# Curis Official Docs v1.0

# 07 MVP Specification（MVP产品实施规范）

版本：v1.0

---

# 1. MVP定位

Curis MVP 是：

> 完整AI组织工作系统的第一可运行版本。

---

MVP不是：

- AI聊天工具；
- ChatGPT替代品；
- 简单任务管理工具；
- 模型管理后台。

---

MVP目标：

验证用户是否可以通过Curis建立AI组织，并完成真实业务。

---

# 2. MVP核心原则

## 原则1：产品模型完整

MVP必须具备：

```
Company

↓

Department

↓

AI Employee

↓

Project

↓

Task

↓

Capability

↓

Artifact
```

---

减少的是：

智能程度。

---

不是：

产品结构。

---

# 3. MVP用户体验目标

用户进入Curis后：

可以：

```
创建AI公司

↓

建立部门

↓

创建AI员工

↓

创建业务项目

↓

配置能力

↓

执行任务

↓

获得成果

↓

沉淀经验
```

---

# 4. MVP核心模块

---

# 4.1 Workspace

## 目标

提供AI工作的统一空间。

---

包含：

- 首页；
- 公司空间；
- 项目入口；
- 成果入口。

---

用户看到：

业务状态。

---

不是：

技术配置。

---

# 4.2 Organization

## 目标

建立AI组织。

---

支持：

```
Company

Department

Employee
```

---

用户可以：

创建部门。

管理AI员工。

---

# 4.3 AI Employee

## 目标

让用户通过员工完成工作。

---

支持：

员工配置：

```
名称

角色

职责

能力

项目关系
```

---

示例：

```
内容负责人

负责：

账号增长项目
```

---

# 4.4 Project

## 目标

项目作为业务执行容器。

---

项目包含：

```
目标

团队

任务

资料

成果

状态
```

---

支持：

任意业务类型。

---

例如：

```
软件研发项目

小红书运营项目

知识研究项目
```

---

# 4.5 Task

## 目标

管理具体执行事项。

---

任务可以来自：

## 用户输入

例如：

“分析竞品账号。”

---

## 项目拆解

例如：

内容项目：

```
热点分析

选题生成

文案制作
```

---

## 员工执行

例如：

研发员工执行代码任务。

---

# 4.6 Capability

## 目标

统一管理AI能力。

---

MVP支持：

```
Model

Agent

Skill

Tool

Workflow

Connector
```

---

方式：

人工配置。

---

# 4.7 Artifact

## 目标

保存业务成果。

---

包括：

- 文档；
- 代码；
- 图片；
- 视频；
- 数据报告。

---

成果必须关联：

```
Task

↓

Employee

↓

Project
```

---

```

```

```
+

```

# 7. MVP Skill处理

已有Skill：

保留。

---

定位：

内部Capability。

---

不是：

能力市场。

---

结构：

```
Existing Skill

↓

Capability Registry

↓

Employee Capability Profile
```

---

例如：

内容团队：

```
热点分析Skill

文案Skill

SEO Skill

图片生成Skill
```

---

# 9. MVP AI能力边界

---

## 支持

- 调用模型；
- 调用Agent；
- 使用Skill；
- 执行Workflow。

---

## 不支持

### 智能调度

不自动判断：

最佳模型。

---

### 自动组建团队

不根据目标自动创建员工。

---

### 自动优化能力

不自动调整Capability。

---

# 10. MVP Memory

支持基础Memory。

---

包括：

## 用户Memory

保存：

用户偏好。

---

## 项目Memory

保存：

项目背景。

---

## 员工Memory

保存：

基础经验。

---

不实现：

自动成长系统。

---
