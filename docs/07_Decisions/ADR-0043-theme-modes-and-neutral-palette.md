# ADR-0043: Theme Modes And Neutral Palette

Status: Frozen

Baseline: `main @ c0e1855f`

Updated: 2026-08-02

Module: Design

## Decision

Curis 只提供三种主题模式：

```text
系统（默认）
浅色
深色
```

三种模式共用同一套布局、组件、间距、字体、交互和语义色。主题只切换中性表面、
文字、边界与对比度。

- 浅色主题以白色和近白色为基础。
- 深色主题以 Codex 风格的深灰为基础，画布使用 `#1a1c1f`，不得使用纯黑。
- 主按钮是主题相关的 CEO 动作色：深色使用品牌绿 `#32f08c`（hover `#0fdc78`，文字 `#0c0c0d`），浅色沿用既有深色 `#30333a`（hover `#17181a`，文字 `#ffffff`）。
- 蓝色只保留给 `status-primary` 的决策 / 信息语义，不再作为全局主按钮颜色。
- 语义色只用于成功、关注、风险和阻塞等经营状态，并以文字或图标补充含义。
- 禁止保留旧版主题 token、页面私有色板或主题专属组件语法。

## Reason

- CEO 需要的是稳定、清爽和可预期的工作环境，而不是多套风格化皮肤。
- 系统 / 浅色 / 深色已经覆盖桌面应用的真实使用场景。
- 深灰而非纯黑可以降低对比刺点，同时保留深色环境的层次。
- 深色使用品牌绿主动作能让 CEO 立即识别“现在可以执行的动作”；浅色使用深色按钮保持克制，避免白色界面被绿色大面积占据。
- 统一语义色和结构，保证 CEO 在不同主题下仍能快速识别风险、决策和执行状态。

## Consequences

- 设计系统只维护一套语义 token，按主题提供浅色与深色值；主动作使用 `action-primary-*` token，不能直接写死 `brand-*`。
- 设置页面需要提供“系统 / 浅色 / 深色”选择，不增加自定义颜色配置。
- 所有页面和 Workspace 必须继承主题 token，不得自行声明颜色。
