## 1. 三条路径定义

| 路径 | 是什么 | 适用 | 成本画像 |
|---|---|---|---|
| **Quick** | 对话 → 直接生成结果（单平台、单条、无闭环） | 一次性/低 stakes/单平台/低合规 | 最低（API $0.15–10/1M token；单篇管线 $0.82–1.40）`[REAL]` |
| **Structured** | 结构化工作（选题→Brief→创作→适配→发布→基础回收） | 品牌一致/多平台/需合规/可测量 | 中（多 Stage，但复用摊薄） |
| **Deep** | 持续监控→研究→内容→多渠道→数据→下一周期（完整闭环） | 经营资产/复利/跨渠道规模 | 高（Deep Research 最贵，白皮书 $3k–10k 当量）`[REAL]` |

**系统按价值与复杂度自动选路径**，用户无需学 Workflow（见 CEO Model §4 Quick Path 保留）。`[CAND]`

## 2. 真实单位经济基准（2025–2026）

### 2.1 单条内容成本
| 类型 | 自由职业者 | 代理公司 | 内部人力折算 | 证据 |
|---|---|---|---|---|
| 社媒帖(含图) | $30–150 | $150–800 | ~$1–2(API)+编辑 | `[REAL]` |
| 1500词博客 | $400–800 | $1,200–2,500 | $300–500 | `[REAL]` |
| B2B 白皮书 | $1,500–5,000 | $3,000–10,000 | 高 | `[REAL]` |
| 短视频口播 | ¥1,500–5,000/脚本 | ¥5,000–20,000 | 低(AI降本80%) | `[COMP]` |

### 2.2 各阶段耗时（典型）
选题挖掘 30min/日、脚本 20min/条、拍摄剪辑 40min/条、发布 10min/条、复盘 30min/日；西方内部团队年成本 $150k–300k `[COMP][REAL]`。

### 2.3 AI vs 人力（实测）
- API 裸成本：GPT-4o ~$2.5/$10 每 1M 输入/输出；Claude 3.5 $3/$15；mini $0.15/$0.60 `[REAL]`。
- 2000 词文章多阶段管线 API **$0.82–1.40**；全包（编辑/QA）**$10–25** vs 纯人力 **$100–500** `[COMP]`。
- **AI 明确赢**：初稿/产品描述/多语言/批量口播（快 10–50×，省 50–90%）`[COMP]`。
- **AI 不赢**：深度研究/品牌语调一致/合规判断/事实核验。原始 GPT-4o 被 AI 检测标记 94–96%，人性化后仍 28–31%，误杀真人 8.7–11.4% `[REAL]` → 「能生成 ≠ 能发稿」。

### 2.4 复用与跨渠道价值（核心杠杆）
1 长文 → 1 博客+3 社媒帖+1 邮件+1 信息图；1 直播 → 35 条短视频；某 SaaS webinar 变博客+LinkedIn+短视频，跨渠道互动 3× `[COMP]`。**单个想法的跨渠道复用是单位经济核心杠杆**——结构化运营在规模化时因复用摊薄而更划算。

## 3. Worth-Doing 判定框架

### 3.1 公式（建议，待 CEO 采纳）
```
WORTH_DOING = (预期业务价值 × 跨渠道复用次数 × 迭代学习收益) > 结构化运营搭建成本
```
- 单条、一次性、单平台、低合规 → 右侧远大于左侧 → **直接生成更划算**（Quick）。
- 多平台、品牌/合规/可测量、需迭代 → 左侧随复用放大 → **专业闭环 WORTH DOING**（Structured/Deep）。`[INF]`

### 3.2 什么时候直接生成反而更好（回答 CEO Q2）
- 单平台、低合规风险、一次性促销文案、灵感头脑风暴、A/B 变体量产 `[INF]`。
- 工具现实边界：ChatGPT/Claude 出初稿需 brief+2–3 变体+人工选优（省 30–40% 写作时间）；Jasper 强 Brand Voice 但 $39–99/seat/月；通用局限=品牌一致靠 prompt、多平台需手动改写、合规不兜底、无测量学习闭环 `[COMP]`。

### 3.3 什么时候 WAIT / SKIP / STOP（系统应主动提示）
| 决策 | 触发 |
|---|---|
| **SKIP 研究** | 短保质期热点内容（研究越重死得越快）`[INF]` |
| **WAIT** | 信号不足/账号养号未达标/平台权限未就绪 `[CURIS-AUTH: Eligibility]` |
| **STOP** | 连续违规风险/超出策略信封/不可逆外部承诺未 Gate `[CURIS-AUTH]` |
| **降级 Quick** | 检测为单条低 stakes → 不走闭环 |

## 4. Progressive Investment（渐进投资，防 Token 烧穿）

| 投资层级 | 触发 | 投入 |
|---|---|---|
| L0 Quick | 默认单条 | 1 次生成 + 1 Channel 适配 |
| L1 Structured | 检测多平台/品牌/合规 | + Brief + 审核 + 数据回收 |
| L2 Deep | 经营资产/复利 | + 持续监控 + Research + 跨渠道 + Learning |

- **Intent 一次生成、N 账号复用**（`HIGH_REUSE`/`FULL_DIVERGENCE`）摊薄成本 `[CURIS-AUTH]`。
- **研究深度绑定内容「保质期」**：evergreen 深研，热点浅研 `[INF]`。
- **上下文隔离**：不预载全量 Workspace/账号资料，路由只取 task-scoped `[CURIS-AUTH]`。
- **批量与复用优先**：资产库跨周期复用，避免每篇从零。

> 防「为一个内容启动十几员工」：按 Responsibility（WHAT）路由，不为每步起人；低音量合并岗位（§6 最小团队）`[CAND][CURIS-AUTH]`。

## 5. 与直接生成工具的对比结论

| 维度 | 直接生成（ChatGPT 等） | Content Growth Professional Workspace |
|---|---|---|
| 品牌一致性 | prompt 维持，易漂移 | Brief/Knowledge 强制一致 |
| 多平台 | 手动改写 | Intent→Variant 自动分叉 |
| 合规 | 不兜底 | 合规闸 + 平台规则 + 防封 |
| 测量/学习 | 无闭环 | 数据→真相→评估→Learning 复利 |
| 资产复用 | 每次从零 | 资产库跨渠道跨周期 |
| 单位经济(规模) | 每次从零更贵 | 复用摊薄更便宜 |
| 适用 | 单条低 stakes | 经营资产/多平台/复利 |

**最终回答 CEO Q1**：系统值得用，当且仅当内容进入「经营资产 / 多平台 / 复利」区间；纯一次性单条，直接生成更优。本系统的价值不在「生成」，而在「让每次生成都汇入闭环并复利」。`[CAND][INF]`
