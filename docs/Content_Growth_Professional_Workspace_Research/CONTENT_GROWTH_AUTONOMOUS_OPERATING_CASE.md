## 1. CEO 输入（仅这三句话 + 一个链接）

> 「我想做菜谱内容……」——**不对，是**：
> 「**我想做 AI 科技内容，主要想涨粉，以后接广告。我很喜欢这个账号（贴链接），想做这种感觉。**」

- **Intent**：AI 科技内容（主题）。
- **Goal / Constraint（用户独有事实 C 类）**：涨粉 → 以后接广告。这是只有 CEO 能定的方向，AI 不替定（Doc1 §5 Envelope：Goal direction 由 CEO 设）。
- **Reference**：一个贴来的账号链接（"想做这种感觉"）。

CEO 此后**不再输入任何专业参数**。下面证明 AI 团队如何据此自主经营。

## 2. 决策链逐段证明

### 2.1 选择定位（对应 Doc1 D01）

- **Evidence**：链接被识别为某 XHS 科技账号；王颖读取其历史——内容类型=新模型实测、受众=科技从业者、表达=第一手口语、更新=周更、增长=靠搜索红利、商业化=接广告。与 CEO「涨粉→接广告」目标兼容。
- **Decision Rule（D01）**：定位 = 用户目标 ∩ 参考账号可学模式 ∩ 赛道空白点；评分维度=相关性/差异化/可达性。候选 ①从业者视角实用测评 ②前沿资讯快报 ③工具横评。
- **Cost-Value**：一次性分析成本中；定位错则后续选题全偏，早期修正成本低 → 值得投入分析（Progressive Investment L1 前置，远小于 L3/L4 浪费）。
- **Confidence**：**MEDIUM→HIGH**（多源一致：参考账号历史 + 用户目标 + 行业常识三向印证）。非 UNKNOWN，事实可复核。
- **Boundary**：定位属**重大方向 → B 建议 + CEO 确认**（Doc1 D01 决策边界）；Envelope **边缘**（影响 Goal 表达）。CEO 看到的是：
  > 「我们建议你这样做：定位=AI 科技从业者视角的实用测评；主发小红书+抖音；调性=可信+前瞻；前 3 周做『新模型实测』系列。预计 6–8 周起量，接广告路径清晰。风险：同质化，用第一手实测拉开。」
  > **[按建议开始] / [调整] / [讨论]**
  CEO 点「按建议开始」→ 后台自动落 Office growth_context（定位/受众/调性/关键词/Source/对标全由 AI 填，**CEO 零字段**）。

### 2.2 找 Source（对应 Doc1 D04 / D05 / D06）

- **Evidence**：① 参考账号互链源（其文中引用的官方/媒体）；② Office 主题「AI 科技」→ 官方博客 OpenAI/Anthropic（VERIFIED 权威）；③ 科技媒体（VERIFIED）；④ 社区 HN/Reddit（MEDIUM 噪声多，作 P1）。
- **Decision Rule（D04/D05/D06）**：Source = 相关性高 ∩ 权威性足 ∩ 更新频繁；分 P0/P1/P2。对标 = 赛道相关 ∩ 增长可解释 ∩ 模式可学 ∩ 非抄袭。关键词 = 高搜索 ∩ 高相关 ∩ 中低竞争。
- **Cost-Value**：发现成本一次性；监控成本随源数线性；按信号量自调频率（项 13-A）。AI **自动发现初始池**，CEO 零 URL 输入（修正 Round 2 R1）。
- **Confidence**：官方源 **HIGH**；社区源 **MEDIUM**。
- **Boundary**：**A 自维护**（项 8/9-A）；用户「重点看这个」自然语言快捷（C 轻量）；专业管理界面 **E 隐藏**。信封内。CEO 全程不见 Source 列表。
- **结果**：建立初始池 = {OpenAI 官博 P0, Anthropic 官博 P0, 3 家科技媒体 P0, 参考互链 P1, HN/Reddit P1} + 8–12 主关键词 + 3–5 可学对标。

### 2.3 推荐 Topic（对应 Doc1 D07 / D08 / D09）

- **Evidence**：监控数小时后，3 源（OpenAI 官博 + 2 媒体）提及「OpenAI 新模型传闻」→ Signal 聚类去重 → Opportunity 评分高（相关×热度×差异）；参考账号同类「实测」内容历史互动高。
- **Decision Rule（D07/D08/D09）**：Opportunity = 多源一致 ∩ 目标相关 ∩ 时效窗口；Topic = Opportunity ∩ 可表达 ∩ 受众想看；排序 = 分高 ∩ 时效紧 ∩ 资源可承载优先。同一 Opportunity 拆 3 角度。
- **Cost-Value**：聚类/生成推荐卡成本极低；过早定稿不浪费（仅进推荐卡待 CEO 看，未升 L3）。
- **Confidence**：多源一致 **HIGH**（Opportunity）；Topic 初评 **MEDIUM**（需后续 Research 验证）。
- **Boundary**：**A 自动聚类+生成推荐**（信封内）；CEO 看 3 张卡（B 呈现）。LOW 孤源 Signal 留观察池不升（不瞎干）。
- **结果**：推荐 3 选题——① GPT-5.6 第一手实测 ② 与 Claude 对比 ③ 一张图看懂新架构。CEO 点①「先调研」。

### 2.4 选择 Research 深度（对应 Doc1 D10 / D11）

- **Evidence**：Topic①「GPT-5.6 实测」= 有官方事实 + 社区争议（性能/定价争论）→ 事实密度高、争议性高。
- **Decision Rule（D10/D11）**：值得 Research = Topic 分 ≥ 阈值 ∩ 现有 Knowledge 不足 ∩ 过价值门；深度 = 争议高/事实密 → L2 Deep，否则 L1。
- **Cost-Value**：L2 成本中；该主题若只 L1 会漏掉社区争议 → 升 L2 物有所值；低分主题则停 L1（严卡价值门，防烧 Token，Doc1 §4.3 反例规避）。
- **Confidence**：**MEDIUM**（深度选择推断）。
- **Boundary**：**A 自判升 L2**（项 14-A，Expert 可改）；信封内。CEO 点「先调研」仅一次确认，Research 全后台。
- **结果**：王颖建 Research Work，多源比对官方文档 + 社区评测 + 媒体解读，标注冲突（社区称「挤牙膏」vs 官方称「代际提升」）为 Unknown 不强行二选一（Frozen `UNKNOWN_IS_LEGAL`）。

### 2.5 选择 Content 方案（对应 Doc1 D12 / D13 / D14 / D15）

- **Evidence**：Research 结论清晰（实测价值明确、切搜索红利）、Content Value 评分达阈值、无合规硬伤；小红书强依赖封面。
- **Decision Rule（D12/D13/D14/D15）**：值得生产 = 结论明确 ∩ 价值≥阈值 ∩ 无硬伤；Draft 默认 1–3 版（单主渠道 1 版够，跨形态差→3）；推荐版=综合分最高∩合规过∩近参考；素材=渠道强依赖视觉→生成 1–2 选 1，优先复用历史高 CTR。
- **Cost-Value**：L3 成本中高；硬产低价值=浪费 → 严卡价值门。多版边际成本可控（上限 3/提示 5）。
- **Confidence**：价值 **MEDIUM**（推断）；推荐版 **MEDIUM**（互动预期，有历史则 HIGH）。
- **Boundary**：**A 自生成推荐成品**（项 23/24/25/27-A）；深度比稿/素材库管理 **E 隐藏**；CEO 看推荐版。UNKNOWN 结论 → STOP/补 Research（不瞎产）。
- **结果**：李想建 Intent+Brief+生成 1 版 Draft（推荐版）+ 自动生成 2 版封面选 1（复用历史高 CTR 构图）。CEO 看推荐成品，说「第二段更口语」「标题换 3 个」→ 李想 Patch 出 v1.1/v1.2（保留 v1 可回滚）；CEO「还是用早一点的」→ 恢复 v1（A 自处理，CEO 不进版本管理器）。

### 2.6 选择 Channel / Account（对应 Doc1 D16 / D17）

- **Evidence**：内容定位「实测」最匹配 XHS 主号与抖音主号（两账号历史互动高、定位近）；抖音主号 `authorization_state=Connected`；XHS 主号 `Connected`。不匹配账号（如个人 IP 号）灰显不强行。
- **Decision Rule（D16/D17）**：Target = 定位匹配 ∩ **Eligibility 满足**(失效/未授权 BLOCKED，Frozen `TARGET_NE_ELIGIBILITY`) ∩ 策略覆盖；Variant 档 = 差异小→HIGH_REUSE(轻)，大→FULL_DIVERGENCE(完全不同)，中→重生成（遵循 `NO_CROSS_ACCOUNT_CONTEXT_LEAK` 不串号）。
- **Cost-Value**：多发边际成本低但风险升；按策略控，不群发所有账号（Frozen `TARGET_IS_ACCOUNT_NOT_PLATFORM`）。
- **Confidence**：匹配 **HIGH**（规则确定）；未授权账号 MEDIUM 但 BLOCKED。
- **Boundary**：**B 建议 + CEO 确认**（项 30-B）；即便 HIGH 匹配仍走确认（不可逆外部动作，Human-in-loop）。Envelope 内（已知账号）。CEO 见：
  > 「建议发布到：小红书主号 + 抖音主号，预计今天 20:00 / 21:00」 **[确认发布] / [调整] / [讨论]**
  不甩账号树（修正 Round 2 R6）。陈帆为 XHS 轻适配、抖音重生成(视频向) Variant。

### 2.7 选择发布时间（对应 Doc1 D18）

- **Evidence**：XHS 主号历史高互动时段=晚 8；抖音主号=晚 9；两平台 scheduling 能力 CONDITIONAL/VERIFIED（支持定时则填，不支持标不支持不写死，Frozen `SCHEDULING_IS_CONDITIONAL`）。
- **Decision Rule（D18）**：时间 = 高互动时段 ∩ 平台支持；不支持定时→标不支持。
- **Cost-Value**：零成本建议；错峰提升互动。
- **Confidence**：**MEDIUM**（时段推断）。
- **Boundary**：**A 建议时间 / 默认立即**（项 32-A）；逐账号精调 **E 隐藏**。信封内。
- **结果**：建议 XHS 20:00 / 抖音 21:00；CEO 点「确认发布」→ 两账号分别走 9 态 per-Account（Frozen `PUBLICATION_PER_ACCOUNT_TRUTH`）。

### 2.8 结果判断（对应 Doc1 D16 评估 / §6 Learning / D21）

- **Evidence（次日数据回流）**：XHS 主号 Published（真实 URL 回填，Frozen `RECEIPT_FROM_CONNECTOR`）；抖音主号 Platform Reviewing→Published；周明 Evaluation：收藏率↑12%，因 GPT-5.6 切中搜索红利；互动集中在「实测对比」段落。
- **Decision Rule（D21 + §6）**：继续 = 策略有效(指标正向) ∩ 资源可续 ∩ 信封内。Learning：单次 Observation 仅记录，**不**直接改 Strategy；需 ≥3 次一致才 Accepted。
- **Cost-Value**：评估成本零；误判停损小。
- **Confidence**：趋势 **MEDIUM**（需多次 Observation 稳固）。
- **Boundary**：**B 建议 + CEO 确认**（项 38-B）；若建议「转带货」= 越信封 → **CEO Gate**（D22）。信封内微调 AI 自调。
- **结果**：CEO 看「上周评估：收藏率↑12%，建议继续并扩抖音」+[按建议继续/讨论/暂缓]；点「按建议继续」→ AI 自动起下一轮（新 Topic/Research）。

### 2.9 下一周期（对应 Doc1 D21 / D22）

- **Evidence**：上轮指标正向 + 「扩抖音」在信封边缘（Channel family 内新增平台倾向）。
- **Decision Rule（D21/D22）**：继续=有效∩可续∩信封内 → B 建议；扩渠道=边缘 → B 报 Leader(周明) 再 CEO 确认；换赛道/变现=越信封 → Gate。
- **Cost-Value**：继续供给成本；扩渠道有 OAuth/维护成本，过早扩稀释精力。
- **Confidence**：**MEDIUM**。
- **Boundary**：**B 建议 + CEO 确认**（信封边缘，项 15 边界）；不自动跨大边界。
- **结果**：下一周期启动，驾驶舱⑧出现新选题；「扩抖音」作为边缘建议待 CEO 确认，未擅自全量扩。

## 4. 关键反「瞎干」机制落点验证

1. **Confidence 闸门生效**：Topic 初评 MEDIUM → 不自动进生产，先 Research；社区争议标 UNKNOWN 不强行二选一（§3.4）。
2. **Progressive Investment 生效**：CEO 一句话不触发 L2+L3+L4 全链；仅高分紧时效 Topic 才升 L2（§2.4）；低分留观察池（§2.3）。
3. **Strategy Envelope 生效**：Goal「涨粉→接广告」由 CEO 定，AI 不替改；「扩抖音」边缘走 B+Leader，不擅自越界；「转带货」会触发 Gate（§2.9）。
4. **Learning 不躁进**：单轮收藏率↑12% 仅记 Observation，不固化策略；需 ≥3 次一致才 Accepted（§2.8）。
5. **Frozen 不变量全程消费**：`TARGET_NE_ELIGIBILITY`(失效仍 Target 仅 BLOCKED)、`PUBLICATION_PER_ACCOUNT_TRUTH`(per-Account 独立)、`NO_CROSS_ACCOUNT_CONTEXT_LEAK`(Variant 不串号)、`RECEIPT_FROM_CONNECTOR`(真实回执)、`UNKNOWN_IS_LEGAL`(不强填)、`SCHEDULING_IS_CONDITIONAL`(不定死定时)。
