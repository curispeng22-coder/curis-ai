## 3. MANUAL DATA ENTRY PRODUCT CANDIDATE

**入口唯一归属：**Publication Detail“录入表现”处理内容级数据；Account Detail“更新账号数据”处理账号级数据。复盘待补队列只是索引，点击打开同一记录。

| Field | Requirement | Behavior |
|---|---|---|
| Account ref | REQUIRED / SYSTEM DERIVED / READ ONLY | 从合法对象进入，不靠名字匹配身份 |
| Publication ref | REQUIRED for post metrics | 账号级观测可无；不能把账号汇总填进一条帖子 |
| metric identity / definition / unit | REQUIRED / SYSTEM DERIVED | 平台与口径限定；播放/曝光、收藏/转发不可混同 |
| value | USER INPUT or reviewed extraction | 实际0合法，空白Unknown；无数据不自动0 |
| observation kind | REQUIRED / SYSTEM DERIVED then confirm | 累计快照或区间增量，不混算 |
| observedAt / window | REQUIRED | 累计截至时点；区间开始/结束与时区 |
| collectedAt | SYSTEM DERIVED | 录入/收集时间，不替代观测时间 |
| source ref | REQUIRED | 平台页/截图/导出文件；无独立证明时标人工自报 |
| provenance / reporter / verification | SYSTEM DERIVED | 人工、同步或辅助提取；不能由用户勾成已验证 |
| correction reason / replaces ref | REQUIRED on correction | 追加订正，保旧值和依据；不覆盖原事实 |
| missing reason | OPTIONAL, required for explicit unavailable | Not Collected/Unsupported/Connection Failed/Stale等消费既有语义 |

采样只问当前判断必需的少量指标；按发布后观察窗口/账号节奏生成提醒，而不是每天30账号×几十字段。支持从同一来源批量辅助提取但逐对象确认，不能跨账号错贴。连续快照可以形成Time Series；累计差值只有口径一致、无重置且窗口有效时才派生，否则Unknown。自动数据与人工数据冲突并存来源并待核验，不按“最新录入”无条件覆盖。

Workbuddy只证明“去录入”及失焦保存数字的操作可发现；没有证明上述历史/时间序列合同，不能将它写成既有参考实现。

## 4. PUBLISHING OPERATION LANGUAGE

| 当前事实 | 可见动作 | 必要输入/反馈 | 结果与Return |
|---|---|---|---|
| 草稿未就绪 | 继续制作 / 提交把关 | 当前版本、缺项、相关账号 | 回制作；不是排期成功 |
| 已就绪、需选择时间 | 安排发布 | 目标账号、时区、本地计划与平台能力区别 | 发布队列同对象 |
| 自动提交可用 | 按已授权计划发布 | 输入/权限/预算/目标重检 | 回执逐账号展示 |
| 自动不支持 | 准备手动发布 | 包、目的地、完成标准 | 原Work等待人；账号仍存在 |
| 用户声称已发布 | 登记发布 / 核验链接 | URL/真实时间/版本/人工来源 | 待核验或经验证事实 |
| 外部效果未知 | 查看平台 / 关联已发布内容 / 核验 | 原请求与目标，远端查询或人工证据 | 确认后接同Publication，不先重发 |
| 确认未生效且可重放 | 重试该账号 | 当前权限及输入未发生实质变化 | 同Work追溯尝试 |
| 已有部分成功 | 查看各账号 / 处理剩余目标 | 读取BEST_EFFORT/ALL_REQUIRED | 不回滚事实，不伪整体状态 |
| OAuth失效 | 重新连接 | Shared/平台正常授权 | 回原目标重新核验，不删账号 |
| 错过计划时点 | 重新判断时效 / 改期提案 | 目标、当前效果、是否仍有意义 | 不能自动补发 |

审核不是所有任务都强制CEO点一次；依据内容风险和批准边界配置，把关活动与P7经营决定分开。不能照抄模板“一切草稿必须人工通过”的规则。

## 5. Entry / Return / state contract

- 每个入口保留Workspace、Surface、对象、筛选、选中项和输入版本；外部平台/Shared Settings返回原Work，重查后继续。
- Empty给真实下一步；Loading保既有内容及范围；Failed说明原因和能否恢复；User Required说明去哪里做什么；Effect Unknown只核验；Interrupted恢复同对象；无权限只显示合法摘要。
- Search按当前池/素材/账号搜索；全公司Search复用Shared。无结果可清筛选或记录新想法，不能清空真实对象。
- AI结果/引用与人工改稿保版本；离开/取消不能伪完成。排序/筛选/切Surface不改变执行状态。
- **待精准验证：**30账号跨品牌筛选负担、制作工作面的版本差异可读性、手录数据窗口选择。它们影响交互验收，不授权当前UI或实现。
