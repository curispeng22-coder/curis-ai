## 3. 复盘必须按此顺序重组

**本期概览 → 可视化趋势 → 对比表现 → 分析判断 → 下一步。**

简介是当前范围、周期、关键变化与数据完整性，不是功能教程。缺数据就地提示，可保集中待补页但不是默认首屏。不建图表墙，默认少量目标相关指标，更多维度按需选择。

### 图表与数据

- 账号：粉丝总量/净增、传播/互动、发布节奏等适用指标的真实示例时间序列；商业结果独立有来源。
- 内容：Publication级曲线＋内容明细表；提供自然日期和发布后相同时长比较，累计与增量清楚。
- 同账号不同内容：至少可选两篇，改变所选对象/指标/窗口会改变图表和明细；未到窗口显示未成熟。
- 同内容跨平台：基于同Intent/Proposal的不同Variant/Publication，不按标题匹配；显示平台账号、版本、形式、Hook/时长、发布时间差异。同口径可比，不同口径并排解释，不强排名。
- 点击图上异常点/区间可进入相关内容/Publication及观测来源；返回保留比较集合、日期、指标和选择。
- 图表有单位、图例、时间轴、数值查看和可阅读明细；不能只靠颜色；在当前窄桌面面板和宽桌面窗口均可用。
- 演示数据明确标“示例/模拟”，来源样例不能伪装为实时同步。缺数不画0；只有两个观测点不能制造每日曲线；来源、定义、验证状态、窗口可查。
- “解释这段变化”携当前范围与证据进入既有员工协作入口；分析后的选题/实验/Work保来源与回程。不重新设计最终Curis Conversation外观。

### 平台手录

复用既有Publication/Account入口，待补只是索引。按平台×内容形式×对象层级显示适用字段，单次只要求当前必要项，可展开更多。完整平台字段仍待官方映射核验，本轮不扩大竞品研究、不伪称全面平台适配。

观测必须有定义/单位、对象、累计截至时间或区间/时区、采集时间、来源与验证状态；计数/百分比/日期校验，0合法、空白Unknown、部分录入保缺口。新增观测可改变示例曲线；纠错留旧值和原因。重开后的本地示例保存方式与限制明确，不伪称服务器持久化。
