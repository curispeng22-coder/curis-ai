# 06 Curis Hybrid — 5 行说明

- **Canvas**：保留 01 奶油白 Canvas、白色 Surface、银灰 Border，主工作区维持安静、适合长时间阅读的氛围。
- **Navigation**：将 01 过重的深蓝 Sidebar 替换为 05 低饱和深灰蓝 `#3A4A52`，导航退后，Main / Work / Artifact 成为视觉主体。
- **Focus**：引入 02 温和黄绿 `#8FB850`，仅用于 Active、Selected、Current Work、Employee Presence、Primary Action。
- **State**：Working 使用 Soft Green；Ready / Accepted 保持更深的 `#1E7A5A`，Focus 绿与 Success 绿语义分明。
- **与 01 最大差异**：Sidebar 从页面第一视觉焦点退化为稳定结构层，绿色成为克制的品牌焦点而非大面积主题色。
