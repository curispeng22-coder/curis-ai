Interactive HTML Prototype

内容在本轮已冻结。不新增 Surface / Dashboard / 模块。唯一解决： 在任意专业工作面看到员工，一点即 Employee Quick Panel → 立即协作；对象 → Utility 不再混淆。

Employee Interaction Contract（一句说明）

  • 员工身份（头像 / 姓名 / Presence Chip / Station 头）一律打开 Employee Quick Panel（Utility）。
  • Panel 内 5 秒可见：当前职责 / 当前工作 / 当前状态 / 当前上下文 / 当前交接 / 最近结果。
  • 主操作「直接对话」一步进入继承当前 Bounded Context 的对话；次操作进入当前工作 / 当前交接；Deep Work 走完整员工工作站。
  • 研究对象 → Research Detail；内容对象 → Content Detail；交接链接 → Handoff Detail。不再全部落到同一个 Content Utility。
  • 无需先到 Team 页面；Main 保持安静，不重复 Surface Tabs；Context 折叠可恢复；CEO Assistant 保持全局浮层。
