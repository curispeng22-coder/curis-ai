# Reviews

This folder contains review notes for completed issues, architecture decisions, and sprint gates.

## Review Rules

- Reviews should be short and evidence-based.
- Start with findings or blockers.
- Include changed files when relevant.
- Include verification evidence.
- Include remaining risks.
- Link the related issue when available.

## Suggested Template

```markdown
# Review: <short title>

## Related Issue

`issues/<issue-file>.md`

## Findings

- None, or list blockers.

## Verification Evidence

- Command and result.

## Risks

- Known risks or gaps.

## Decision

Accepted | Needs revision | Blocked
```
