## 独立核对

| 优先级 | HTTP | 唯一职责 |
| --- | --- | --- |
| 1 | `401` | 身份域缺失或无效 |
| 2 | `400` | 输入参数形态错误 |
| 3 | `403` | 授权失败、跨域或对象归属错配 |
| 4 | `404` | 对象不存在或状态不可见 |

- 多条件同时命中时只取最高优先项并立即终止。
- 任一失败不得返回 `200`，不得继续读取子对象。
- `401/400/403/404` 逐字复用 8a.1a.3a exact body。
- 响应仅允许 `error_code`、`message`，不得按来源、实体、归属字段、状态或查询路径增加差异。
- 已不存在“401/403/404 呈前置优先”的冲突表述；`400` 明确低于 `401`、高于 `403/404`。
