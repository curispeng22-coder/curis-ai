# ADR-002: Capability Provider Instead of Rebuilding Tools

Status: Deprecated

## Status

Accepted

## Context

The product must support software development, content operations, video production, writing, investment, and e-commerce. Rebuilding all specialized tools is unrealistic.

## Decision

Curis Workspace will not rebuild mature platforms. It will integrate, manage, and orchestrate Capability Providers.

## Consequences

- Faster development.
- Clearer architecture.
- Better extensibility.
- Product value focuses on orchestration, workflow, context, and cost control.
